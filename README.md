# Yonder · 由达

**由你出发，抵达更多可能。**

Yonder 是一个由 AI Agent 驱动的桌面伙伴，也是你在数字世界中的能力延伸。

你表达意图，它协助行动；你示范操作，它记录过程。当相似的任务再次出现，你们就不必从头开始。

我们希望它有温度、有个性，也有真正把事情做完的能力。

> 🚧 项目正在规划与开发中。以下描述为产品愿景与计划能力，具体可用功能以实际发布版本为准。

## 你的意图，它的行动

日常工作经常散落在浏览器、桌面应用和重复操作之间。

Yonder 希望把这些操作连接起来，让你可以对身边的桌面伙伴说：

- “打开这些页面，把我需要的信息整理好。”
- “把下载的文件分类，再把数据填进表格。”
- “记住我接下来怎么操作，下次帮我完成。”
- “把刚才的流程再执行一遍，这次换成新的文件。”

从一句话到一连串操作，Yonder 让你的意图能够抵达更多地方。

## 计划能力

### 桌面伙伴

以桌宠的形式常驻桌面，通过对话、动作和状态反馈与你互动。

它可以安静陪伴，也可以在你需要时开始工作。你能够知道它正在做什么、在哪里遇到困难，以及什么时候需要你参与。

### Agent 驱动

将自然语言意图转化为可执行步骤，结合当前环境选择工具，并根据执行结果继续推进。

遇到不确定的情况时，向你澄清；需要你接手时，保留清晰的任务上下文。

### Browser Use

在浏览器中浏览页面、查找信息、填写表单，并完成跨页面的操作流程。

让你的目标贯穿多个页面，减少反复点击和信息搬运。

### Computer Use

通过观察桌面界面、点击、输入和快捷键，与桌面应用交互。

把需要跨应用完成的事情，连接成一个连续任务。

### Record & Replay

通过示范教会 Yonder 一个流程：

1. 开始录制，完成一次操作。
2. 查看记录，补充步骤说明和可变参数。
3. 保存流程，在需要时再次执行。
4. 遇到环境变化或执行异常时暂停，由你确认或接手。

录制与回放将从可重复的操作步骤起步，逐步探索结合上下文的适应性执行。

## 有个性，也尊重你的节奏

我们希望 Yonder 的人性化体现在每天的相处方式中：

- **表达清楚**：让你看得懂它的状态、计划和执行结果。
- **适度主动**：需要时提供帮助，专注时减少打扰。
- **诚实反馈**：区分已完成、正在尝试和无法完成的事情。
- **记忆可控**：由你决定哪些习惯和流程值得保留。
- **随时接手**：任务可以暂停、取消，也可以交还给你。

陪伴感来自稳定、体贴、值得信任的行为。

## 行动边界

能够操作电脑，也意味着需要清晰的控制方式。以下是计划遵循的设计原则：

- 执行范围与工具权限应当明确，并允许用户调整。
- 涉及对外发送、支付或不可逆修改时，设置明确的确认步骤。
- 录制过程应可见、可暂停，并支持排除敏感内容。
- 执行记录应可检查，保存的数据应可删除。
- 回放前检查必要条件，遇到异常时停止并反馈。
