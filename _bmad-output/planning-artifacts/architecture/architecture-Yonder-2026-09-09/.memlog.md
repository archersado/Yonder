- (decision) 建立 OOXML 架构 Spike：Word/Excel/PowerPoint 分别使用 Office 与 WPS 真实样本，验证读取、局部修改、另存及重新打开；未修改结构必须保持，Office/WPS 打开不得出现修复提示；加密、宏、复杂图表等超范围结构必须安全拒绝或完整保留；记录耗时、内存峰值、安装包增量和失败类型。任一核心格式无法安全修改则淘汰该候选；结果形成 ADR 并确定唯一实现。
- (decision) 锁定 Cloud Connector：Yonder 仅主动建立单一长期 WSS 出站连接，不开放公网监听端口；连接承载任务请求、状态事件和心跳。首次设备配对取得设备凭据并存入系统 Credential Store；断线指数退避重连，并从 last_sequence 补传 Outbox。云端与本地请求进入同一 Agent Gateway 与权限边界；云端故障不得影响本地 Agent、CLI、Recording 和本地任务。MVP 不实现通用 HTTP Server、端口映射或 P2P；外部平台定义业务协议，Yonder 仅实现版本化 Connector Port。
- (decision) 锁定个人上下文采集默认策略：用户启用 Yonder 后可持续采集当前窗口与应用元数据；文档内容与浏览记录按数据源单独授权且默认关闭；用户操作序列仅在手动开始 Recording Session 后采集。原始数据本地优先保存，云端连接不触发自动上传；云端 Agent 仅能按任务显式请求，返回前检查授权、范围与敏感字段。用户可查看采集状态、暂停、删除单条或清空某类数据。密码框、隐私窗口、系统安全界面始终排除。上下文记录包含来源、采集时间、应用、保留期限和敏感等级。
- (decision) 锁定本地上下文存储：SQLite 保存来源、时间、应用、文件引用、权限、敏感等级和生命周期等元数据；较大正文保存在应用数据目录，SQLite 仅保存相对路径与哈希。使用 SQLite FTS5 提供关键词与时间线检索；Agent 只能经 Context Port 查询，不得直接访问数据库或数据目录；默认返回摘要和引用，正文需再次显式读取。删除须同步清除索引、正文文件及未发送 Outbox。MVP 不引入本地向量数据库、Embedding 模型或知识图谱，语义加工由外部个人上下文产品承担。
- (decision) 锁定浏览记录采集：BUA 任务期间复用 ego-lite/ego-browser 页面事件并关联任务；日常浏览通过 Chromium 扩展采集 URL、标题、访问时间与标签页事件，扩展经 Native Messaging Host 连接 Yonder，不开放本地 HTTP 端口。禁止直接读取 Chrome/Edge 正在使用的 History SQLite。无痕/隐私窗口始终排除。MVP 支持 Chrome、Edge，其他 Chromium 浏览器按兼容性验证；Safari、Firefox 延后。
- (decision) 锁定当前窗口与应用感知：Windows 使用 WinEvent Hooks + UI Automation；macOS 使用 NSWorkspace + Accessibility API/AXObserver；统一映射为 ForegroundContext（应用标识、进程、窗口标题、文档引用、时间范围）。默认仅记录元数据，正文或控件内容需独立数据源授权；采用事件通知，不使用持续高频截图或轮询。无辅助功能权限时降级到应用级信息且不反复提示；系统安全界面、密码管理器和用户排除应用不采集。原生 Adapter 仅上报事件，去重、会话切分和持久化由 Application 层负责。
- (decision) 锁定文档内容采集：仅处理用户明确授权的目录/文件或任务明确选择的文件；由文件打开、保存或最近活动事件触发，不扫描用户磁盘。按内容哈希去重；OOXML 复用 Document Adapter，纯文本和 PDF 使用只读 Extractor。MVP 不做 OCR，不索引图片或扫描版 PDF。仅保存提取文本、结构摘要和原文件引用，不复制原文件；移动时按文件标识与哈希尝试关联，无法确认则新建记录；删除文件或撤销授权时同步删除提取内容与索引。禁止全盘扫描、后台递归发现和网络盘自动采集。
- (decision) 锁定本地上下文保留策略：普通上下文默认 90 天，用户可选 7/30/90 天或永久；Recording 原始素材默认 30 天，生成的可回放 CUA Trajectory 长期保留；任务截图、命令输出等执行附件默认 7 天；用户固定内容不自动清理。每日低优先级清理正文、索引、附件及对应未发送 Outbox。远端数据由外部个人上下文产品执行其保留策略，Yonder 仅展示同步状态，不虚假承诺远端删除完成。
- (decision) 锁定本地静态加密：SQLite 使用 SQLCipher，使元数据与 FTS 索引一并加密；截图、正文附件和 Recording 素材使用文件级加密。设备主密钥随机生成，仅存 macOS Keychain/Windows Credential Manager；云端凭据与内容密钥分离。日志、文件名和临时文件不得泄漏正文；应用锁定或退出时关闭数据库并清理临时明文。不自研密码算法，MVP 不实现跨设备密钥同步；密钥丢失时本地数据不可恢复，只能清除后重新采集。
- (decision) 锁定轻量级性能预算：空闲 CPU 平均低于 1%，空闲内存目标低于 150MB，托盘启动至可用低于 3 秒，窗口切换事件至状态更新低于 300ms。CUA Driver、Node Document Worker 和 ego-lite 均按需启动并在空闲后退出；无任务时禁止截图循环、DOM 轮询和高频文件扫描；解析、加密与索引进入后台队列，不阻塞桌宠动画。CI/发布验证分别记录 Windows/macOS 的 CPU、内存与启动时间；外部 Driver 开销与 Yonder Core 分开报告。
- (decision) 锁定执行并发：CUA 使用唯一前台桌面执行租约，同一时间仅一个任务控制鼠标键盘；检测到用户主动操作时自动暂停并释放输入控制。BUA MVP 同时只运行一个 ego-lite Task Space。Command、只读 File Tools 和 Context 查询可后台并行；文件/文档写入按规范化绝对路径互斥，同一文件禁止并发写。高风险确认仅阻塞对应任务。调度默认 FIFO，用户前台任务可提高优先级。Agent 断开不自动取消任务，租约到期转 waiting/reconnect。排队、获租约、暂停和恢复全部进入统一任务事件流。
- (decision) 锁定操作来源隔离：输入事件标记 user、agent_cua 或 replay；Recording 默认仅将 user 事件转换为轨迹，Agent/Replay 输入只进入审计且不得再次录制。用户在 CUA 期间输入视为接管并暂停任务，继续前必须重新 Observe。BUA 页面事件关联外部 Task Space，不混入日常浏览会话；File/Document/Command 操作均携带调用来源与 Agent 身份。
- (decision) 锁定统一 Agent Tool 调用协议：所有能力调用携带 request_id、agent_id、capability、deadline；创建任务支持 idempotency_key 防止传输重试导致重复执行。即时查询直接返回，长任务返回 task_id，并统一支持 task.get/task.cancel/task.events。错误分类为参数错误、权限不足、用户拒绝、资源冲突、执行失败、超时、结果未知、能力不可用。cancel 仅表示取消请求，执行器确认停止后方可标 cancelled；副作用操作超时或断连标 unknown 且禁止自动重试。File/Document/Command 支持 validate，MVP 不提供通用 dry-run。响应携带协议版本、能力版本和结构化错误信息。
- (decision) 锁定能力发现：gateway.hello 返回协议版本、平台及能力清单；能力包含 name/version/availability/reason，availability 为 available、permission_required、dependency_missing 或 temporarily_unavailable。返回 CUA Driver、ego-lite、OOXML Adapter 等执行器及版本，但握手不得启动 Office/WPS、浏览器或文件管理器。权限或 Driver 状态变化发送 capabilities.changed。Agent 必须按清单选路；Yonder 不静默切换执行器，所有降级建议显式返回并由 Agent 决定。
- (decision) 锁定组件交付：基础包包含桌宠、Rust Core、CLI/MCP、IPC Gateway、File/Context 基础能力；CUA Driver、ego-lite BUA、浏览器扩展及可能的 Node Document Worker 为受管可选组件，首次启用时由用户触发安装。组件版本由 release manifest 固定并校验签名与 SHA-256，安装在 Yonder 私有目录，不污染系统运行时或 PATH；Agent 不得指定任意下载源、包名或版本。升级失败保留上一版本且组件可独立禁用；离线时基础能力可用，缺失组件报告 dependency_missing。
- (decision) 锁定系统权限申请：首次启动仅申请基础权限；CUA 启用时申请辅助功能/屏幕录制，Recording 启用时申请输入监听，目录采集通过系统选择器授予范围，浏览记录由扩展独立展示权限。每项权限映射 capability，拒绝只禁用相关能力；UI 展示用途、状态和系统设置入口。权限恢复发送 capabilities.changed，无须重启应用。测试覆盖允许、拒绝、撤销和运行中变化。
- (decision) 锁定个人上下文同步：仅用户启用的类别进入 Outbox；记录使用稳定 record_id、内容哈希和版本，服务端按 ID 幂等接收。正文/附件分块并支持断点续传，元数据先行、内容按需；服务端确认后标 synced，未确认前不删除待发送记录；更新生成新版本。本地删除已同步数据生成 Tombstone，Yonder 区分删除请求已接收与远端删除已确认。失败指数退避，不阻塞本地采集/检索/任务。WSS 使用 TLS；因云端需处理正文，MVP 不做服务端不可解密的 E2EE。同步与 Agent 任务共用连接，但消息类型和流控隔离。
- (decision) 锁定磁盘与背压：默认本地配额 5GB；始终预留至少 500MB 或磁盘剩余空间 5%（取较大约束），不得写满磁盘。软上限优先清理过期且未固定的任务附件与 Recording 原始素材；不得自动删除未同步上下文、CUA Trajectory 或固定内容。硬上限暂停新附件、截图和 Recording，但继续保存最小任务状态/错误。Outbox 超限时暂停对应类别同步与采集并通知用户；解析与同步采用有界队列。空间恢复后低风险采集可自动恢复，Recording 必须由用户重新开始。
- (correction) 研发顺序修正：所有影响技术路线的候选必须先完成架构 Spike 和可行性门禁，产出 ADR 后才进入产品实施 Epic；不得在 CUA Driver、ego-lite 集成、OOXML 实现、跨平台 IPC/系统感知、加密存储等尚未验证时，将其作为 Story 的既定实现方案。
