# AD-DS-03 运行中任务先筛选后分页

状态：Accepted（2026-09-18，DS-S2 进行中视图修复）。

## 背景

DS-S2 已规定“进行中”只显示 `running`。现有桌面先请求“全部未结束任务”的一页，再在展示层过滤；当该页被 `created`、`paused` 或 `interrupted` 占满时，真实运行任务可能位于后页，首屏却显示为空。

## 决定

`task.list` 协议 1.16 增加默认 `false` 的可选布尔参数 `running_only`。参数为 `true` 时，TaskStore 必须在授权范围和游标条件之后、`ORDER BY/LIMIT` 分页之前，以持久化状态 `running` 过滤。`include_finished` 在此模式下不扩大结果集。

沿用既有任务 ID 排序、排他游标、页大小和授权规则；SQLite 当前状态表仍是唯一事实源。桌面“进行中”请求 `running_only=true`，不再依赖客户端页内过滤。旧请求省略字段时行为不变；Agent Gateway 仅向协商 1.16 的会话接受该字段。

## 边界

不新增查询端点、索引、状态枚举或第二套任务视图，不改变任务状态机和事务。若未来需要任意多状态组合，再以实际需求扩展过滤协议；本次只实现已确认的 `running` 视图。
