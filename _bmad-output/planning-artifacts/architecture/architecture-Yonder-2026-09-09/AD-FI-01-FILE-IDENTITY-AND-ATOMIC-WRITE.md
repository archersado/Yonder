# AD-FI-01 文件身份与原子写入

状态：Proposed  
日期：2026-09-17  
关联：FI-S1、DO-S2

## 决策问题

路径字符串不能作为同文件互斥身份。软链接、硬链接、大小写和重命名可能让不同路径指向同一文件；Document写入还必须识别宿主锁并在同卷原子提交。

## 候选决策

输入必须是规范化绝对路径；既有文件身份在macOS使用`st_dev + st_ino`，Windows使用volume serial + file index。新输出先规范化既有父目录并拒绝越出授权根。写租约按文件身份而非路径持有；软链接和硬链接不得取得第二写租约。

写入使用目标目录内独占创建的临时文件，完成格式校验和flush后原子rename。目标存在、身份变化、文件锁、跨卷、权限或提交结果不明均稳定失败，不自动重试。删除仍只进入系统回收站，不在本决策实现。

macOS候选使用`File::try_lock`检测宿主占用。WPS真实DOCX对照已证明打开时拒绝锁、关闭后可取得；无需依赖进程名或旁车锁文件。

## Spike门禁

统一样本覆盖软链接、硬链接、父目录逃逸、同文件锁与同目录原子替换；另用Office/WPS真实打开文件验证锁语义。macOS与Windows证据齐备前保持Proposed，FI-S1和DO-S2不得接产品Gateway。
