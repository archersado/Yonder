# AD-TM-07 Agent任务命名与接管工作定位

状态：Accepted（产品边界）；名称技术字段、协议版本与迁移已按文末定稿；接管目标协议仍待AG/TM/CU/DS联合定稿。日期2026-09-14；关联AG-S2、TM-S1/S3、DS-S2、CU-S2。Architecture Impact：architecture-change（任务元数据与人工工作定位）。

## 需求来源

原产品简报Task Space多任务状态/任务可见、权限模型逐任务控制，架构唯一事实源/执行目标身份；本次用户明确：点击接管要打开正在操作的工作并切到对应屏幕，任务名称由Agent根据任务创建。沿用AD-AG-01 Agent专属创建、AD-TM-03显式接管记录、AD-CU-01 SDK-only。

## 产品决定

Agent创建任务时提供与任务内容对应的简短名称，Yonder只校验/保存/展示，不调用模型生成、从说明自动概括或支持人工创建命名。名称与说明分别保留；可信归属由Gateway AuthContext绑定。名称须进入同一SQLite事实源并随快照/列表展示，创建幂等比较须包含名称，重试不能悄悄改名或生成新任务。已有缺名称记录不伪造Agent命名，兼容及显示反馈另定。

点击执行中任务“接管”：立即冻结Agent新动作并发起停止确认；确认后定位此任务当前步骤正在操作的工作窗口，使它在所属系统桌面/Space与显示器上可见并前置。不是把窗口拖到小龙所在屏幕，不移动小龙或复制任务空间。工作引用来自可信执行/Observe，不按名称模糊打开应用，也不任意执行Agent提供的路径/命令。

窗口最小化时可恢复；窗口/文档关闭、身份失效或Space切换失败时保持任务暂停，提示“未能定位任务工作，请手动打开”，不自动创建空白文档或切到其他同名窗口。需重新打开已关闭文件/页面时，必须沿已授权资源引用验证身份和现有File/BUA边界；尚无可靠引用则不自动打开。BUA复用外部任务引用，不能复制ego-lite Task Space。

定位结果、停止确认与Recording分别可观测；未确认停止不称已移交，定位失败不自动恢复Agent。只有停止/目标身份/隐私及用户显式录制条件满足后才启动本次接管记录；普通切屏/输入不自动录制。目标定位失败后用户自行打开工作的接管/记录顺序待联合设计，不据此实现采集。

## 实施围栏

先完善相关Story三份设计，再定稿技术ADR与OpenSpec；名称可以独立于原生停止链路推进，但协议Rust单一来源、输入边界、创建原子性/幂等及安全迁移不能省略。接管定位要求macOS/Windows各自多显示器/不同Space、最小化/目标丢失原生证据；Windows仍按用户暂缓，不把单平台通过称完整完成。

## Agent名称技术定稿（2026-09-14）

状态：Accepted（仅名称子范围）；接管目标、attempt与Worker身份协议仍待定。本次工程审阅确认名称不改变Domain状态机、Application持有DTO、Adapter持有SQLite，UI只消费Rust生成的协议。

协议1.3新增create.name与snapshot.name，Rust使用可缺省Option并在缺省时不序列化；新协商1.3要求创建名称，1.0–1.2读快照保持原字段形状、1.1–1.2允许历史无名称创建，低版本携带名称拒绝-32010。支持登记的宿主向1.3客户端声明task.read/task.create为1.3，task.cancel仍1.2。旧请求同键不同名称（包括有/无）冲突-32009，不改既有任务。

工程输入限额：名称为1–256 UTF-8字节、trim后非空、不得含控制字符；原样保存，MVP无改名接口。此限额是工程设计，不是原产品简报原文。统一校验函数由Rust Protocol定义，Application和Adapter复用Application的校验出口。

SQLite schema5在tasks新增nullable name作为当前事实，task_creations新增nullable name保存原始幂等创建参数；3→5同事务迁移，历史NULL保持NULL，状态/事件/Outbox/说明原样保留。2先沿既有登记迁移，4仅沿AD-TM-06严格检查兼容未使用实验列，再升级5，不重用实验版本4。已有明文库升级前用SQLite VACUUM INTO生成同目录唯一、不覆盖的完整备份；备份失败禁止升级，DDL失败回滚。已有加密库不得自动升级，本次保留原入口但拒绝旧版本迁移；全新授权加密测试库可初始化5，现有5可读取。不增加依赖。

桌面卡片与详情标题用Agent名称，task_id另列；缺名称显示“未命名历史任务”，不伪称Agent命名。所有文本使用textContent，标题保留完整名称供无障碍读取，原hover/按钮/数据保留语义不变。验证要求包含版本兼容、名称边界、重试冲突、取消后重试、迁移/备份及原生卡片证据；Windows按用户暂缓，完整Story不Done/Archive。
