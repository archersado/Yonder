- (constraint) 继承 ARCHITECTURE-SPINE：CUA Driver 必须模型无关；Application 拥有任务状态、派发准入、唯一前台桌面租约与每步 Observe；Driver 不得持有第二状态机。
- (constraint) 继承 AD-CU-02/04 与 AD-TM-08：用户输入立即冻结新动作；超时、断连、崩溃或交付不明为 unknown 且不得自动重试；Worker 生命周期退出不构成安全停止证明。
- (constraint) 当前 Accepted 基线仍为 trycua 0.25.0；agent-desktop 未完成双平台 Spike 前不得替换产品依赖、进入 Gateway 或长期形成双执行栈。
- (decision) 新增 CU-S4 独立限时 Spike，而不改写 CU-S1 当前选型；该决策绑定候选路线的验证边界，防止未验证技术覆盖已接受基线。
- (decision) agent-desktop 仅作为低层引擎候选，通过 Yonder ComputerUse Port 接入；其命令模型、MCP、任务控制和 lease 语义不得泄漏进 Domain/Application，防止形成第二套协议与状态所有者。
- (decision) 候选 C ABI 或最小桥必须运行在 Yonder 监管的独立 Worker 中，通过继承 stdio 或既有私有 IPC 通信，禁止加载进 Desktop 主进程或开放本地 HTTP/TCP，防止故障域扩大与无法终止卡住调用。
- (decision) 取消分级：未派发及步骤间可确定取消；在途动作只能终止 Worker并按可能已交付处理为 unknown，随后新鲜 Observe 与交回外部 Agent，防止把进程退出误报为副作用已撤销。
- (decision) 用户输入观察器只维护 generation 与安全枚举，不记录按键、文本或轨迹正文；generation 变化先冻结后续派发，再请求 Worker 停止，防止隐私扩大与用户/合成输入混淆。
- (decision) 允许集仅含 snapshot、qualified ref 动作与经验证窗口操作；禁用 raw 坐标、Windows 无目标按键、--force、CDP、上游 MCP、默认 trace 与 screenshots，hit-test unknown 必须 fail closed，防止目标漂移和本地端口/敏感数据暴露。
- (decision) 正常动作由 Application 强制后置 Observe；delivered_unverified、Observe失败、断连或结果缺少完整 disposition 均映射 unknown 且不重试，防止 Driver 成功响应被误当任务事实。
- (direction) Spike 期限五个工作日；固定 agent-desktop v1.1.0 源码 revision 与自建制品，Windows/macOS 使用相同样本和结构化证据。
- (direction) 统一样本覆盖同名双窗口、应用重启/句柄复用、前后台切换、真实用户输入抢占、动作超时/Worker断连、96/192 DPI、多显示器、权限拒绝、Notepad/TextEdit 与 Electron 应用。
- (decision) 淘汰条件：用户输入后仍派发下一动作；用户与合成输入不可可靠区分；目标身份变化发生误投递；Worker终止后lease或输入状态残留；结果不能稳定归为已Observe验证或unknown不重试；无法自建并由Yonder完成OS签名；干净Windows依赖未声明运行库。
- (question) Spike 后仅允许三种 ADR 结论：双平台共享引擎、仅单平台且证明收益足以承担双栈成本、或淘汰；第二种若无显著可靠性收益必须淘汰，避免长期双执行栈。
- (decision) Reviewer Gate后冻结唯一上游源码为v1.1.0 commit d3dc190afbf34cd2377252398ddd5c30efbd093a，不允许为绕过CRT缺陷漂移到后续commit。
- (decision) 统一实现入口为受监管Worker内最小Rust bridge，bridge/v1通过inherited stdio JSONL保留完整disposition；不再允许C ABI/CLI/其他IPC多选。
- (decision) 删除单平台采用出口；任一平台硬门槛失败整体淘汰agent-desktop候选，防止长期trycua/agent-desktop双栈。
- (decision) 派发、用户抢占、取消共用Application-owned admission gate；完整JSONL帧flush为唯一线性化点，之前not_dispatched，之后in_flight。
- (decision) 输入分类冻结为driver_current_attempt/user/unknown/observer_lost；只有绑定当前attempt与Worker的合成事件不冻结，observer异常一律fail closed。
- (decision) Worker清理失败进入global desktop quarantine；仅只读恢复程序或宿主重启可解除，禁止合成key-up/button-up补偿。
- (decision) 冻结agent-desktop-spike-evidence/v1与sample catalog v1；Observe通过同时依赖预冻结predicate和独立只读target identity oracle。
- (direction) 双平台固定任务集增加Windows WPS/文件资源管理器与macOS Office/Finder；环境缺失保持未完成，已安装但unsupported触发淘汰。
- (event) Reviewer Gate critical/high findings reconciled into AD-CU-07, CU-S4 Story and OpenSpec; pending re-review and final status.
- (event) spine finalized after rubric, reality, adversarial, structure and prose reviews; CU-S4 ready for Spike, AD-CU-07 remains Proposed
