# CM-S1 macOS 结构化命令 Runtime 证据

本目录记录 CM-S1 内部 Runtime/Port 的无正文结构化验证结果。

- 参数按字面数组传递，不经 Shell 展开。
- 环境先清空，再只注入显式有界键值。
- stdout/stderr 分别限制为 64 KiB。
- 超时、取消和输出超限会停止父进程及后台后代。
- 父进程退出后若仍有后代，不误报成功，清理后返回 `unknown`。

测试只创建隔离的 `/tmp` 标记文件及短生命周期进程，不读取正式任务库或用户文件。此增量没有 UI，也不申请系统权限，因此不生成截图；macOS Driver 行为由结构化测试结果覆盖。Windows 验证按用户决定延期，产品路径保持 unavailable。
