# FI-S1 临时文件授权引用核心证据

本目录记录无正文的 Application 授权合约与 macOS 新目标预检结果。

- 只有可信 LocalUser 可为当前任务签发授权；Agent、跨任务、跨 owner 和用途变更均拒绝。
- 授权最多 256 项、最长 15 分钟，只驻留进程内；读取可复用，副作用用途一次消费。
- 既有文件只记录身份与 SHA-256，不保存正文；新目标绑定规范父目录身份。
- 父目录身份不符、目标已存在或授权根逃逸均不创建文件。

本增量不含 UI、Gateway 或系统权限请求，因此没有截图；所有文件样本位于唯一临时目录。Windows 按用户决定延期，产品路径保持 unavailable。
