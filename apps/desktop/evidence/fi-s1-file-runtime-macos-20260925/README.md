# FI-S1 macOS 受控文件 Runtime 证据

本目录记录内部 File Port/Adapter 的无正文结构化验证结果。

- 原路径、软链接和硬链接归并到同一文件身份。
- 规范化授权根阻止链接逃逸，读取和写入均限制为 16 MiB。
- 新建不覆盖竞争目标；替换绑定读取时身份与 SHA-256。
- 进程内写租约与宿主 advisory lock 分别失败关闭。
- 暂存校验失败不改目标；提交后同步失败返回 unknown。
- Agent 不能取得回收站能力；系统回收站测试只移动自建临时夹具，验证后已从回收站清理。

此增量没有 UI，也不申请系统权限，因此不生成截图。macOS File Driver 由结构化测试日志和既有 WPS 原生锁证据覆盖；Windows 验证按用户决定延期，产品路径保持 unavailable。
