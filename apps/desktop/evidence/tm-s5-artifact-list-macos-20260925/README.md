# TM-S5 产物清单 Task Space macOS 证据

本目录只使用明确测试夹具，不读取正式任务库、文件正文或用户产物。验证协议 1.26 对应的 Task Space 清单展示、四种可用性、固定版本分页、局部失败保留及确认版本变化提示。

## 结果

- Ego Lite TaskSpace 123 在 macOS 上执行完整 Task Space 回归，使用同一空间恢复两次超时诊断后完成并关闭；没有访问用户浏览器上下文。
- 空清单明确显示“该版本没有产物”，确认版本与当前版本相等时不误报变化。
- 当前版本 2、确认版本 1 时显示“产物已变化，需重新检查”；第一页加载 20/21 项，四种可用性均显示，reference ID 只作为次要文本。
- 第二页故障时保留 20 项并显示“重试加载产物”；重试使用固定版本 2、`after_ordinal=20`、`limit=20`，最终加载第 21 项。
- 同轮还覆盖时间线、确认、浏览器关联、迟到响应和列表筛选回归，结构化断言全部为 true，见 [`result.json`](result.json)。
- [`task-space-artifacts.png`](task-space-artifacts.png) 为同轮 Task Space 页面截图；截图停在详情滚动区顶部，没有单独作为条目文案的证明，条目文案以同轮 DOM 结构化结果为准。
