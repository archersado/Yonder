# Yonda 九状态素材 v4

来源：[互动动画生命周期-v1](../互动动画生命周期-v1.md)、用户背景格子残留和播放不丝滑反馈。内置imagegen重新生成同角色纯绿色分离底图；沿用用户已明确授权的Python/Pillow，输出真实透明RGBA帧，全部生成原图保留。绿色不是交付背景，source文件仅用于追溯。

`frames/`为透明PNG序列；`asset-plan.json`声明尺寸、时长、帧序及保持/循环/单次；`prompts.json`记录本批完整提示词。200×200逻辑窗口使用400×400帧，录制标记独立。研发脚本不随素材包发布。

透明验收必须检查龙角、尾巴、翅膀及脚部空隙，并在深浅纯色背景人工查看。仅有alpha通道不足以通过，不复用失败v2的通过结论。新运行时播放先受控单实例预览，失败立即恢复旧图；背景与动画平滑度分别验收。运行时仍仅开放有真实来源的四状态，其余五态不伪造。

待命固定姿态保留连续呼吸；执行序列连续平滑混合，不能用四帧索引变化代替丝滑验收。Windows按用户要求暂缓。原生证据和独立结论见OpenSpec的verification-state-playback-macos.md，不将素材生成称完整Story Done。

复验：36张RGBA深浅背景未见格子，绿色可见残留像素0。四状态已用于单实例正式宿主研发预览；待命真实macOS连续截图确认双眼闭合再睁开。执行全图淡化有重影已拒绝，最终用新专注关键姿态和独立左右爪连续运动。其余五事件态素材仅保存未启用；完整原生任务链路仍待验证。
