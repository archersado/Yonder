# 九态连续动作局部分层

复用并保留 lifecycle-v4/v5 原帧，无新增原图生成。经用户授权 Pillow 拆分；prepare_heads.py 提取头部和身体，窄颈部补片来自同帧腹部；prepare_gestures.py 提取前臂及翼片，前臂分离区的身体补片来自已保留的 v6 torso。运行时副本位于 apps/desktop/ui/runtime/lifecycle-v7。

头、眼使用相同局部矩阵；爪/翼使用肩/翼根锚点；等待、暂停、完成均单姿态连续变换，不进行整图帧混合。完成小跳采用余弦起落，起跳与落地速度归零。所有动作不改变真实任务状态或发布事件。

限制：暂停只驱动右翼；首版为透明PNG局部分层，不是完整骨骼绑定。接缝仍需原生动态目测，Windows暂缓；五个真实来源未接线状态只在预览展示。
