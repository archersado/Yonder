# 录制相机道具 v8

使用内置 imagegen 生成单个蓝白软质3D相机，提示词要求透明背景、无文字、无角色、无背景棋盘、独立玩具道具、圆形深蓝镜头与小红灯。生成原图保留为 camera-source.png；该图仍含外部光晕，未直接用于桌宠。

按用户已授权的 Pillow 去背景/拆分流程，用圆角轮廓去掉外部背景与光晕，生成400像素透明画布 camera.png；相机主体仅占84×52。录制前臂从既有 recording-00.png 分离，身体补片只作用于前臂遮罩；原帧保留。

4.8秒循环：平滑举起、停留、镜头附近短暂柔和闪光、平滑放下。相机和前臂共享矩阵；渲染顺序为前臂、相机、前方指尖，保证镜头可见。红灯为相机上的静态标记。减少动态效果停止装饰循环/闪光，保持道具。仅在录制预览模拟，不调用真实录制或拍照能力。

运行时副本在 apps/desktop/ui/runtime/lifecycle-v8。prepare_camera.py 含透明边界/画布自检。最终自然程度及原生版本仍待验收。
