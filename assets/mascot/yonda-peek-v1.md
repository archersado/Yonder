# Yonda 趴在边缘探头素材

由内置 image_gen 基于原小龙生成，文件为 `yonda-peek-v1.png`，带真实 alpha。用于屏幕工作区下沿休眠入口：身体藏在边缘后，露出相连的头部、一双眼睛和小爪子，不是悬浮眼球。原生显示尺寸为 112×56 逻辑像素，点击恢复原位。

## 完整提示词

Use case: identity-preserve. 为参考图中的同一只 Yonda 幼龙制作桌面宠物的隐藏状态 PNG 素材。角色必须保持奶白皮肤、浅蓝龙角、大而清澈的蓝金色眼睛和柔软3D质感。新姿势：小龙身体完全藏在屏幕下边缘之外，趴在边缘后面，仅从下方探出圆圆脑袋的上半部和一双睁开的眼睛，两只眼睛同一水平线看向用户，亲切又有点调皮，像躲在桌子下面偷偷看你。两只很小的前爪可以搭在下沿。画面下缘裁掉鼻子以下的面部和整个身体，不能出现全身，不能把眼睛画成两颗脱离脸的眼球。横向约2:1的紧凑构图，头部居中，四周留少量安全边距。不要画桌子、屏幕、框、底板、地面、投影、文字、棋盘格或其他角色。背景必须是实际 PNG alpha 透明，而不是用灰白格或白底假装透明。该素材会贴在屏幕底边，用两只眼睛表示小龙正躲在边缘后面。
