# AG-S10 视觉与交互设计

## 入口与流程

点击发送后按钮进入禁用态并显示“正在发送给 Agent…”。结果处理如下：

- 已接受：进入等待回复或既有“请在 Agent 中查看回答”状态。
- 已拒绝：图片和问题保持原样，输入恢复可编辑，显示“Agent 拒绝了本次输入；内容已保留，可重试”。
- 附件过大：图片和问题保持原样，发送禁用，显示“截图超过 4 MiB；请缩小选区后重新圈选”。
- 送达未知：图片和问题保持原样，发送禁用，显示“是否送达未知；为避免重复，不可重试，请关闭或重新圈选”。
- 其他发送前错误：保留现场并给出具体原因；可安全重试的错误恢复发送按钮。

## 状态与错误反馈

错误不能只用颜色表达。保留“重新圈选”和“取消/关闭”入口；不可重试状态必须通过文本和禁用态同时表达。用户明确重新圈选或关闭时，才清除本次临时截图和问题。

## 无障碍与平台验证

状态文本使用既有可读区域；焦点回到问题框或保留在错误后的可操作控件。macOS 正式宿主提供结构化日志/截图证据，Windows 继续 Deferred，不用 macOS 证据替代。
