# AG-S11 视觉与交互设计

## 入口与流程

沿用圈选回复卡。Agent delta 到达时在同一回复区域逐步形成段落、标题、列表、引用和代码块，不新开窗口，也不抢焦点。

## 状态与错误反馈

- 渲染中的未闭合标记按普通文本显示，补齐后自然转为格式化内容。
- 代码块使用等宽字体与横向滚动；引用和列表使用轻量层级，不压缩状态区与操作按钮。
- 图片只显示“图片：替代文本”的占位；不支持或危险链接显示为普通带样式文本，不自动打开。
- 回复失败、中断、截断继续使用 AG-S9 的明确状态文案，已渲染内容保留为可能不完整。

## 无障碍与平台验证

使用语义化 `h2/h3/h4`、`p`、`ul/ol`、`blockquote`、`pre/code`；回复容器保留 `role=document`、键盘焦点、文本选择和复制。macOS 正式宿主验证，Windows 继续 Deferred。
