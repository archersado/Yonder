# AG-S12 视觉与交互设计

## 入口与流程

Markdown 列表必须显示稳定的圆点或十进制编号，项目缩进与正文左边界形成清晰层级；松散列表保留适度项目间距，不拆成多个视觉列表。代码、引用和链接继续沿用 AG-S11 样式。

## 拖动交互

卡片顶部的 `YONDA · 圈选提问` 与标题组成拖动区，鼠标悬停显示可移动光标。按下并拖动时由原生窗口系统跟随指针；关闭按钮保留独立点击区域。正文、截图、问题输入、回复选择区、滚动区及底部按钮不属于拖动区。

拖动不会关闭、提交、重新圈选或取消 Agent 回复。重新打开圈选卡时仍按当前选区自动定位，不恢复上次人工位置。

## 状态与错误反馈

拖动不新增业务状态。原生拖动命令不可用时卡片保持原位，输入、回复和关闭操作继续可用；不把拖动失败显示成 Agent 回复失败。

## 无障碍与平台验证

拖动不是完成提问的必需操作，键盘流程不受影响。标题和回复的可访问语义保持不变。macOS 需提供原生窗口移动前后结构化位置证据；Windows 原生证据 Deferred。
