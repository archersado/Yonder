# AG-S13 产品需求

## 问题与目标

多个 Codex 输入会话并存会把 thread 路由责任错误地推给用户。产品应维持单一活动输入会话：后连接的已认证会话抢占旧会话，所有新输入和回复关联自然落到唯一目标。

## 范围与非目标

### 范围

1. `AgentInputHub` 同时最多持有一个可接收输入的 AgentSession。
2. 新会话注册时替换旧会话，并通知旧连接退出。
3. 新会话注册完成即成为圈选、直接语音和同类输入的唯一目标，无人工选择步骤。
4. 旧连接的延迟 unregister 不得删除新会话。
5. 被抢占会话的未完成回复关联必须清除并显示中断，不得进入新会话。
6. Agent 管理不显示在线输入会话列表，不提供 session/thread 选择。
7. 抢占状态只驻运行时内存，不进入 SQLite、事件、Outbox、日志或索引。
8. 被抢占 Connector 必须收到明确终止原因并退出；不得把抢占关闭当作 Yonder 重启而自动重连争抢。

### 非目标

- 不建立聊天历史、会话目录、会话重命名或持久化路由。
- 不允许多个输入会话并发，不提供人工切换或恢复旧 thread。
- 不改变任务 Gateway 的多连接语义、Agent 注册授权或任务归属。
- 不改变任务 Gateway 请求、任务状态或持久化协议；只允许增加本地 AgentSession 的有界关闭帧。

## 验收条件

- AG13-01：零会话时输入明确不可用；首个会话连接后自动成为唯一目标。
- AG13-02：第二个已认证会话连接时，旧会话收到关闭信号且 Hub 只保留新会话。
- AG13-03：抢占后圈选和语音输入只进入新会话，旧会话不再收到正文或附件。
- AG13-04：旧连接延迟 unregister 不影响当前会话；当前会话 unregister 后输入通道离线。
- AG13-05：被抢占会话的进行中回复变为中断，旧 delta 不得污染新会话。
- AG13-06：Agent 管理不展示在线会话、引用或选择按钮。
- AG13-07：抢占竞态中的输入失败保留原圈选问题与截图，可在新会话就绪后重试。
- AG13-08：选择状态、会话引用和持久化 schema 均不新增。
- AG13-09：旧 Connector 收到 `preempted` 后不再注册；真实传输故障与 Yonder 重启仍保持既有有界重连。

## 需求来源与验收映射

| 类型 | 来源 | 对应验收 |
|---|---|---|
| 后续用户变更 | 2026-10-15 主人明确“正常只能连一个会话，是抢占式的” | AG13-01～08 |
| 原始问题 | 多会话导致输入目标不确定和用户不可理解的选择步骤 | AG13-02、03、06 |
| 架构约束 | AD-AG-11 当前输入/回复短生命关联与禁止猜测 | AG13-03～05、08 |
| 安全边界 | 会话身份、正文和路由不得持久化或记录 | AG13-06、08 |
