# AG-S13 视觉与交互设计

## 入口与流程

### Agent 管理

Agent 管理继续显示已登记 Agent 与语音回复设置，不显示“在线输入会话”、会话编号、当前接收目标或选择按钮。连接抢占属于运行时机制，不向用户暴露 thread 路由。

## 状态与错误反馈

### 圈选与语音输入

- 输入通道在线时直接发送到唯一当前会话，不增加选择步骤。
- 抢占瞬间若提交未送达，保留问题与截图并显示稳定的“输入通道已切换，请重试”反馈。
- 输入通道离线时显示“当前没有可接收输入的 Agent；内容已保留”。
- 不显示“请选择接收输入的 Agent”或“选择接收会话”。

## 无障碍与平台验证

桌宠仍只显示任务通道与输入通道是否连接，不显示内部会话数量。macOS 正式验证覆盖两个真实连接的抢占、旧连接退出、唯一目标回复朗读与停止；Windows 随 AG-S8 继续 Deferred。
