# AG-S13 视觉与交互设计

## 入口与流程

### Agent 管理

在现有“已登记 Agent”和“语音回复”之间增加“在线输入会话”区块。每行显示：

- Agent ID；
- `会话 1`、`会话 2` 等当前进程内序号；
- “支持截图 / 支持回复”的有界能力摘要；
- “当前接收目标”或“选择”按钮。

不得显示完整 session/thread ID。只有一个会话时显示“已自动选择”；多会话且无目标时在区块顶部显示“请选择圈选与语音输入的接收会话”。

## 状态与错误反馈

- 选择成功：该行显示“当前接收目标”，状态区显示“已选择 codex-cli · 会话 N”。
- 会话在点击前断开：显示“该会话已断开，请重新选择”，立即刷新列表。
- 列表读取失败：保留已渲染内容并显示稳定错误，不伪造当前目标。
- 按钮具有稳定中文名称，可用键盘触发；当前目标不能只靠颜色表达。
- 原圈选卡的草稿、截图和错误提示保持不变；用户选定目标后返回卡片重试即可。
- 圈选提交因多会话无目标被拒绝时，状态旁直接显示“选择接收会话”；点击打开 Agent 管理而不关闭或清空圈选卡。选择完成后，圈选卡提示“已选择接收会话，可重新发送”并隐藏该入口。

## 无障碍与平台验证

macOS 正式验证必须覆盖键盘选择、当前目标的非颜色表达、多会话增减和返回原圈选卡重试。Windows 随 AG-S8 继续 Deferred，不以 macOS 结果替代。
