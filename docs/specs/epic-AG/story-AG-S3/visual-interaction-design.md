# AG-S3 调用交互设计

## 入口与流程

无新UI。Agent握手后declare步骤，成功回执表示“Agent声明已登记”，不是动作开始；get/current和events可查看声明。用户仍通过小龙既有hover面板操作真实任务，本子范围不增加步骤编辑/人工创建入口，不新增全屏或独立App。

## 状态与错误反馈

declare回执分开已接受声明序号与当前任务序号；重试/取消后读取不得显示正在执行。无声明明确null，旧历史不伪造。调用方稳定区分版本/握手、身份、参数、序号冲突、标签冲突、任务已开始、配额和存储失败；错误不自动重试写入。协议旧客户端只收到既有形状及状态未变事件。

## 无障碍与平台验证

没有新增控件、动画或原生窗口。调用结果纯结构化，不靠颜色/动画区分声明；后续DS当前步骤展示必须文字说明来源为Agent声明。首批库/stdio验证对应STEP-01～06，不宣称Windows/macOS原生UI已验；Windows按用户暂缓。具体错误与兼容规则见AD-AG-04。
