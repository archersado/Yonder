# AG-S5 视觉交互设计

## 入口与流程

调用方显示“正在发送给〈Agent名称〉”；accepted后短暂显示“已交给智能体”并自动收起。连接不存在、超时或拒绝时原位显示具体错误与“重试/取消”。

语音调用方不提供发送确认或正文编辑；开始收音就是本轮投递意图。圈选等其他入口是否需要编辑由各自Story决定，不由Gateway强制。

## 状态与错误反馈

状态可被屏幕阅读器读取，不能只靠动画或颜色；重复点击重试沿用同一`input_id`，界面不得在未收到ack时显示成功。

仅连接一个可接收输入的Agent时不增加选择步骤。多个Agent同时可用且没有激活会话时，收音前在桌宠轻量菜单列出Agent显示名；选中后标记为当前会话。收音开始后面板显示目标Agent名称，期间不因新连接或活跃顺序变化而切换目标。

## 无障碍与平台验证

桌宠始终显示小型Agent连接徽标：绿色表示至少一个可接收输入的会话已连接，灰色表示未连接。徽标不得替换或遮挡生命周期动作；可访问名称同步读出“Agent已连接/未连接”，不能只依靠颜色。首个连接建立或最后连接断开时，隐藏中的桌宠主动唤醒以让变化可见。
