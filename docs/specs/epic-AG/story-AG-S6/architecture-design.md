# AG-S6 架构设计

## 边界与依赖

本 Story 只扩展本地 Agent 管理能力，不改变现有 Gateway、CLI/MCP 或任务协议。依赖方向保持 `desktop → adapters/application → domain/protocol`。

## 数据与事务

本地 Agent 注册信息持久化在 SQLite，与任务状态同库。撤权写操作与任务状态更新保持同一事务边界，不能出现“已撤权但仍可新建任务”的中间态。

## 状态与契约

注册记录仅包含逻辑身份、状态和时间戳，不保存本地凭据或传输密钥。撤权后：

- 活动会话立即终止。
- 该 Agent 禁止新建任务、提交步骤、控制任务和接收输入。
- 已有任务仍保持可见，用户可查看和终止。

## 失败与验证

验证必须覆盖登记、禁用、撤权、重启恢复、撤权后任务可见性，以及撤权后新建请求被拒绝。不得用模拟状态替代真实 SQLite 与本地会话验证。
