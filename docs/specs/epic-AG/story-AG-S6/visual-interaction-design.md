# AG-S6 视觉交互设计

## 入口与流程

在本地设置中提供“Agent 管理”入口。列表展示已登记 Agent、当前状态和最近连接时间。

用户可以点击“禁用”或“撤权”。撤权前弹出确认提示。

## 状态与错误反馈

- 禁用成功后返回“已禁用”状态，Agent 不再接收新任务。
- 撤权成功后返回“已撤权”状态，活动会话立即断开。
- 已有任务保留在任务列表中，界面提示“该 Agent 已不再可用”。

## 无障碍与平台验证

- 列表和状态必须可被屏幕阅读器读取。
- 撤权按钮必须提供明确的键盘操作路径。
- macOS 与 Windows 分别验证本地设置入口、撤权反馈和已有任务保留表现。
