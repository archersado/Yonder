# AG-S7 视觉交互设计

## 入口与流程

正常使用时用户不应看到 thread ID、Socket、环境变量或桥接命令。启动 Yonder 与受支持的 Codex 客户端后，桌宠连接徽标自动从“未连接”进入“正在连接”再到“慢脑输入已连接”。

## 状态与错误反馈

- `任务通道已连接；慢脑输入已连接`：Gateway 与输入/replan 均可用。
- `任务通道已连接；正在恢复慢脑输入`：连接器在有界重连，任务读取和创建仍可用。
- `仅任务通道已连接`：MCP/Gateway 可用，但没有当前会话输入能力。
- `当前 Codex 客户端不支持慢脑回注`：客户端只暴露私有 stdio 或没有受支持接口。
- `等待当前 Codex 会话授权连接`：存在支持能力，但尚无明确会话注册。

状态必须同时提供文字和可访问名称，不能只靠徽标颜色。任务执行状态优先，连接状态作为独立副信息，不覆盖“执行中、等待用户、重新规划”等任务事实。

## 错误与恢复

- 自动重连期间不弹出重复确认，不要求用户复制技术参数。
- 超过有界重连窗口后提供“查看连接诊断”，只显示客户端类型、通道状态、稳定错误码和建议动作，不显示正文、完整 endpoint、thread ID 或 Payload。
- 会话切换导致旧绑定失效时显示“Codex 会话已切换，等待新会话连接”，不得把输入发往旧 thread。
- 不支持的 ChatGPT Desktop 版本应明确说明限制，不引导用户执行无法恢复当前会话的无效重启。

## 无障碍与平台验证

所有连接状态必须具有屏幕阅读器可读文本、键盘可达的诊断入口，并保持任务状态优先级。Spike 的 UI 证据可使用隔离诊断页或结构化状态日志，不得把原型状态冒充已发布功能。后续产品 Story 需分别提供 macOS/Windows 原生截图或视频及屏幕阅读器文本证据。
