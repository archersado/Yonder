# AG-S9 视觉与交互设计

## 入口与流程

沿用现有圈选确认卡，不新建聊天窗口。发送成功后保留截图缩略图与问题摘要区域，正文输入框切换为只读回答区。

状态顺序：

1. `正在发送给 Agent…`：尚未收到 input accepted。
2. `Agent 正在回复…`：accepted 且已收到 started；显示轻量加载状态。
3. `Agent 回复`：按增量追加正文，保持可选择、可复制，不自动抢占焦点。
4. `回答完成`：只在成功终态显示；提供“关闭”和“继续圈选”。
5. `回复失败/回复已中断`：保留已收到的有界正文并明确其不完整，提供关闭和重新圈选。

## 状态与错误反馈

- 用户可在等待或流式阶段关闭卡片；关闭不取消 Agent 当前 turn，也不在后台保存回答。
- 不支持回复能力时显示“已发送；请在 Agent 中查看回答”，按原行为有界关闭。
- 64 KiB 上限触发时显示“回答过长，已截断”，不得静默截断。
- 卡片只接受当前 `input_id + session_id` 的严格递增事件；迟到或错配事件不可闪现。
- 回复区域支持键盘选择、复制与 VoiceOver；阶段不能只靠颜色表达。

## 无障碍与平台验证

macOS 正式窗口验证必须覆盖键盘关闭、正文选择复制、VoiceOver 状态朗读以及成功/失败/中断/截断文本。Windows 证据继续 Deferred，不复用 macOS 截图替代。
