# BU-S1 视觉交互设计

## 入口与流程

任务总览只关联外部 Task Space 入口和状态；接管来自用户明确操作，成功后切到 ego-lite 对应空间。不可用原因明确显示，Yonda 不承载浏览器页面。

## 状态与错误反馈

呈现真实可观察状态；加载、等待、失败和未提供能力不能伪装为完成。无独立界面时由调用方界面或结构化响应承载，不额外建立窗口。

## 无障碍与平台验证

有 UI 的按钮提供名称与可见焦点，支持键盘，减少动态效果遵循系统偏好；无 UI 时保证调用错误稳定可区分。原生交互须各平台独立证据。

## 待决事项

当前增量无新增 Yonda 面板；外部入口接入 DS-S2 前只提供结构化结果。Windows Runtime 延期，不能宣称双平台 BUA 可用。
