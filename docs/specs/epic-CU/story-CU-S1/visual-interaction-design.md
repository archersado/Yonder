# CU-S1 视觉交互设计

## 入口与流程

SDK-only用户变更与AD-CU-01：无上游App、独立窗口或服务入口，STOP-SDK01–04只读监督结果由布尔/分类反馈。显示SDK子进程就绪/退出/断连/超时和原生输入停止仍未验证，不启用接管/Recording或弹出权限设置。

权限拒绝、用户输入暂停和观察失败可见；保留各平台原生证据。

## 状态与错误反馈

STOP-DRAIN01–03无产品入口变化，仅原生隔离输入窗加可选延迟模式，显示固定测试标记。结构化结果区分原生setter开始、应用、SDK输入返回、关闭确认及最终Observe；只输出布尔、时间与安全枚举，不保存输入/AX正文。执行中排空未通过时仍不启用接管。

STOP-IN01权限不足由结构化结果明确返回“SDK当前宿主Accessibility未授权；未派发输入”，不自动打开权限设置或启动录制。STOP-IN02–03为临时隔离输入测试窗，不是新增分发App；失败不向其他窗口输入，结果仅测试标记是否匹配/长度/分类，不保存原始AX正文或截图。

呈现真实可观察状态；加载、等待、失败和未提供能力不能伪装为完成。无独立界面时由调用方界面或结构化响应承载，不额外建立窗口。

## 无障碍与平台验证

有 UI 的按钮提供名称与可见焦点，支持键盘，减少动态效果遵循系统偏好；无 UI 时保证调用错误稳定可区分。原生交互须各平台独立证据。

## 待决事项

Windows 选型已有证据；macOS 和 Office 延期，不改称全部完成。
