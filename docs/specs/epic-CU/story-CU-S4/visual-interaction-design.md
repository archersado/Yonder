# CU-S4 视觉交互设计

## Spike呈现

本Spike无产品UI。终端只输出候选版本、样本阶段、结果分类和布尔后置事实；不输出截图、窗口标题、输入内容、完整工具参数或SDK Payload。

## 未来产品状态约束

若路线通过，动作级前台投递仍属于CUA桌面控制：从尝试开始至恢复原前台或交回期间，顶部浮窗持续显示当前计划步骤。前台切换不是新任务，也不能隐藏任务面板中的进行中状态。

计划步骤至少区分“聚焦目标控件”“输入内容”“验证结果”；只有后置Observe确认的步骤显示成功图标。`unverifiable`、恢复失败或目标失效显示黄色待核实并交回，不显示绿色完成。

## 接管与无障碍

只有用户在顶部浮窗显式点击接管才停止后续步骤；普通输入事件不自动接管。浮窗提供可访问名称、当前步骤文字和非颜色状态标记。Spike不实施这些UI，只验证未来状态所需事实是否可得。
