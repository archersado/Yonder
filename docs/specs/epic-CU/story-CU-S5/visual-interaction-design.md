# CU-S5 视觉交互设计

## 入口与流程

计划最后一个步骤完成后，浮窗保留计划步骤和成功图标，并把汇总状态改为“等待慢脑核验最终结果”；不能先消失或显示任务完成。

核验为 achieved 时显示“目标已核验”，随后由归属 Agent 完成任务；核验为 not-achieved 时显示“目标未完成，已交回慢脑”，保留既有步骤结果并等待新计划。

## 无障碍与平台验证

浮窗不展示慢脑思维链、截图、AX transcript、正文或完整 Payload。三种状态均提供可访问文字与非颜色图标；读屏顺序为任务、当前步骤、目标核验状态、接管操作。

## 状态与错误反馈

陈旧核验或缺少核验时不把任务标红为执行失败，显示“需要基于最新画面重新核验”。用户显式接管和取消沿既有入口处理。
