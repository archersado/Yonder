# CU-S6 视觉交互设计

## 入口与流程

临时 transcript 与元素句柄不直接展示在顶部浮窗或任务面板。用户仍只看到慢脑提交的步骤标签、当前执行步骤、成功/待核实图标及交回原因，不看到 AX 标签、索引或完整控件树。

计划执行响应在需要 replan 时携带当前 `observation_ref` 与有界可操作元素列表。慢脑优先选择语义匹配且唯一的句柄；不存在、不唯一或不可操作时才使用同次截图做视觉候选。

截图响应同时提供原始像素宽高。慢脑从缩放预览选择位置时，必须换算回原图像素并把同次 `observation_ref` 放入候选；预览尺寸未知或引用已更新时不显示为可执行视觉动作。

## 状态与错误反馈

引用过期、Worker 重建、索引消失、截图尺寸变化、坐标越界或动作后状态未变化时，顶部只显示“界面已变化，需要重新观察”或“当前步骤待核实”，不得暴露元素文本或把失败步骤标为成功。

## 无障碍与平台验证

该扩展不新增依赖颜色、图像细节或精确指针操作的用户入口；顶部状态继续提供文字与图标双重反馈。macOS 以真实 Retina 显示器上的 Sky 应用截图验证原图坐标，Windows 原生证据按主人决定暂缓且不得由 macOS 结果外推。
