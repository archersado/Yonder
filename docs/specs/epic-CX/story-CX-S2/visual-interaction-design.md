# CX-S2 视觉交互设计

## 入口与流程

Windows/macOS所有用户界面统一使用“圈选提问”，不出现“指针模式”。入口可位于小龙轻量菜单和系统托盘；快捷键只作为补充，并在设置中可见、可修改、可关闭。

### 自然交互流程

1. 用户悬停小龙，在左侧轻量“⌑”图标选择“圈选提问”；系统托盘保留同名入口。
2. 当前显示器出现一次透明选择层。顶部以紧凑工具条提供“框选 / 画圈”和取消；画圈的紫色轨迹实时跟随，系统取笔画包围区域。选择层不改变原工作窗口的前台位置。
3. 松开后立即退出选择层，在区域旁显示完整、无蒙层的轻量确认卡：截图缩略图、“来源：应用名”、问题输入、麦克风按钮、重新圈选、发送、取消。来源不可用时显示“来源：当前桌面”，不显示空白或技术错误。
4. 点击麦克风后在问题框显示实时转写；最终非空转写直接携带当前截图提交，不再要求点击“发送”。文字输入仍由用户点击“发送”。
5. Agent创建任务后，小龙才进入对应忙碌动画，任务面板显示Agent给出的名称。

直接点击而未形成有效区域时，进入“仅提问”卡片，不截图；屏幕录制权限缺失时也进入同一卡片并明确说明截图未包含。两种路径均可编辑文字并发送，重新圈选仍保留；用户也可取消。

## 状态与错误反馈

- 选择中：边框和尺寸可见，不显示无关工具。
- 待确认：清楚展示将要发送的截图与文字。
- 权限缺失：提供对应系统设置入口和“仅文字/语音提问”。
- 提交中：禁用重复发送，保留取消查看入口。
- 语音输入中：麦克风按钮显示停止，问题框展示部分转写；关闭、取消、重新圈选或超时立即停止收音。
- 提交未知：明确提示“是否送达未知”，允许用户自行决定是否重试。
- 附件尚未就绪或校验失败：保持确认卡并显示“截图未发送”，允许重新圈选或取消，不降级成伪成功的纯文字发送。
- CUA正在控制桌面：入口先显示“正在暂停当前任务…”，真实暂停成功后自动进入圈选；无法确认停止时不显示选择层，并提示“当前任务结果待核实，暂不能圈选”。

## 无障碍与平台验证

圈选层是短生命周期工具层，不是Yonder的全屏应用形态；结束后小龙仍在原固定位置。键盘可完成取消、重新圈选和发送；高对比度下边界可见，减少动态效果时取消轨迹动画。屏幕阅读器使用坐标/尺寸摘要和截图预览替代文本。

### 平台验证

Windows/macOS分别验证主屏、副屏、不同缩放、负坐标、全屏应用、权限拒绝、Esc取消、切屏和异常清场；证据不得包含真实敏感截图正文。
