# DO-S2 产品需求

## 问题与目标

Agent需要在不操作XML、不依赖Office/WPS私有插件的情况下读取并局部修改DOCX/XLSX/PPTX。系统默认另存，保留未修改内容，并把复杂或不支持的编辑明确交回Agent决定是否降级CUA。

## 范围与非目标

首批分两段实施：先支持有界结构化读取和正文唯一文本节点替换；FI-S1通过后再接另存、`expected_hash`冲突保护和原子输出。按单元格地址写值、跨多个文本run替换、宏、旧二进制格式、复杂图表、版式重构和自动降级CUA暂不支持。

## 验收条件

- DO2-01：调用方只提交文档、工作表、幻灯片和文本语义，不接触ZIP entry、XML路径或命名空间。
- DO2-02：读取返回有界结构化内容和当前文件hash，不把整份原始XML或文件正文写日志。
- DO2-03：修改必须携带`expected_hash`，默认写入不同输出路径；原文件变化时返回稳定冲突且不产生输出。
- DO2-04：输出先写同卷临时文件，结构与关系校验通过后原子提交；失败清理本次临时文件。
- DO2-05：未修改part的解压后字节保持一致；DOCX/XLSX/PPTX均有统一样本。
- DO2-06：Office/WPS锁、同文件别名冲突、目标已存在和不支持内容返回可区分错误，不绕过宿主锁。
- DO2-07：真实Agent任务经统一Gateway、任务步骤、Observe与完成链路调用；未知副作用不自动重试。

## 需求来源

- 产品简报「目标用户与工作场景」「两条执行路径」「MVP主干链路」。
- 架构主干「Command、File 与 Document」：Document Port不暴露XML，默认另存，覆盖需显式请求，使用`expected_hash`、临时文件、结构校验和原子替换。
- Accepted AD-E0-04：Rust进程内，固定`zip 6.0.0`、`quick-xml 0.42.0`、`sha2 0.10.9`，Node Worker淘汰。
- FI-S1负责路径、文件身份、互斥、回收站和锁边界；DO-S2不复制File Adapter。
