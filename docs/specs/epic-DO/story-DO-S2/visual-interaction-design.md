# DO-S2 视觉交互设计

## 入口与流程

首批无独立编辑窗口。Agent在任务步骤中提交读取或修改；Task Space展示真实步骤、执行状态和产物路径。复杂操作提示“当前Document能力不支持”，由Agent决定是否请求CUA，不自动切换执行方式。

## 状态与错误反馈

读取、写入中、等待文件解锁、冲突、失败和成功必须区分。成功显示另存产物路径与hash；冲突显示源文件已变化；锁冲突保持任务等待或暂停，不伪装成功。

## 无障碍与平台验证

默认另存无需覆盖确认。覆盖、删除或高风险外部发送必须使用可信本地确认，Agent参数不能自报确认。所有按钮支持键盘焦点；无UI调用返回稳定错误码和简短中文说明。

### 平台证据

macOS与Windows分别用本机Office/WPS或结构化打开日志验证；Windows按用户决定暂缓，不据此关闭完整Story。
