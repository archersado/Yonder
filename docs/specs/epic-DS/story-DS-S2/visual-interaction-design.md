## 入口与流程

自然交互细化（后续用户要求优先）：轻点清醒小龙直接打开贴身任务menu，同时保留点头反馈；按住移动超过既有4像素阈值只拖动，拖动前收起menu；点休眠双眼只先唤醒。键盘Enter/Space与轻点一致，不因减少动态效果而阻断功能。menu点击外部、Escape或关闭收起，入口不再要求额外悬浮按钮；完整环绕多功能图标仍保持后续Story待办。本次仅实现任务入口。

最新用户变更优先：小龙旁一个轻量任务按钮唤出任务menu，避免独立应用面板形态。菜单透明无装饰、小尺寸圆角卡片，靠小龙同屏展开，超出屏幕时翻到上方或夹入工作区。默认隐藏，Escape/关闭返回小龙，不提供全屏/最大化。首批单个任务入口不等于实现暂停的完整环绕功能菜单；列表选择后下方显示真实详情。此前独立面板截图只保留技术验证历史。

2026-09-14首批入口工程定稿：系统托盘提供“任务总览”，打开520×440左右的辅助面板（工程初始尺寸，可后续调整）；Escape、面板关闭按钮或窗口关闭隐藏，托盘可再次打开。无全屏/最大化，不实现环绕图标。左侧进行中/全部任务列表，右侧详情，刷新与下一页明确可达；原生窗口标题为“Yonda · Task Space”。这是独立正式面板预览，当前E0小龙未迁入，不宣称已统一忙碌门禁。

契约联审修订：首批页面名称采用“进行中/全部”，替代下述早期“进行中/历史”布局建议，因为既有include_finished=true返回全部。任务行首批显示ID、Agent、真实状态；缺失名称/等待原因等明确未提供，不伪造。独立历史筛选需求保留后续契约依赖。

2026-09-14待审布局：轻量浮动辅助面板，顶部名称、刷新、关闭；进行中/历史切换，下方任务列表与选中详情。任务行显示实际任务名称或ID、Agent、状态、等待摘要；有真实进度时才显示，不用运行时长推算百分比。错误与等待同时保留明确文字，不只依靠颜色。

环绕图标菜单仍按用户要求暂缓；该面板入口的最终产品形式待联审，不因总览开发顺带实施DS-S3。浏览器详情提供“打开浏览器Task Space”，外部引用缺失或能力未提供时说明原因。

加载显示读取中；授权内无任务显示暂无任务；失败显示读取失败与重试；旧数据保留时标记状态可能过期。详情读取失败与列表失败分开反馈。关闭返回桌宠，Escape关闭，Tab按面板按钮/任务行/详情动作顺序导航，焦点可见；关闭后恢复入口焦点。减少动态效果下不播放面板过渡。

尺寸、面板靠屏幕边定位及是否支持调整大小均为待审建议，不写成用户要求。平台证据包含真实两任务、等待、错误、空列表、外部Task Space入口及键盘路径；Windows暂缓仍保留门禁。

进行中/历史列表、任务详情、等待原因、加载/空/错误状态与键盘访问；具体布局待设计。

## 状态与错误反馈

呈现真实可观察状态；加载、等待、失败和未提供能力不能伪装为完成。无独立界面时由调用方界面或结构化响应承载，不额外建立窗口。

## 无障碍与平台验证

有 UI 的按钮提供名称与可见焦点，支持键盘，减少动态效果遵循系统偏好；无 UI 时保证调用错误稳定可区分。原生交互须各平台独立证据。

## 悬停入口变更（2026-09-14）

后续用户明确改为悬停小龙显示任务菜单，不再由点击打开。清醒小龙连续悬停200毫秒后显示贴身菜单；快速经过和开始拖动取消待打开。轻点仅动作反馈，休眠双眼轻点只唤醒。Enter/Space保留键盘菜单入口。悬停显示不请求原生焦点，当前应用可继续输入；进入菜单后可操作关闭，菜单失焦后隐藏。菜单不随离开小龙立即消失，以便跨越间隙进入菜单。

2026-09-23用户变更：清醒小龙右键可直接唤起任务menu，并阻止系统上下文菜单；无未结束任务、休眠或拖动时仍不打开。轻点仍仅反馈，悬停与Enter/Space保留。

## 有任务才显示与忙碌形象（2026-09-14用户变更）

用户再次指出悬停未显示，并明确要求无任务不弹面板、有任务运行时显示忙碌动画。此处“有任务”定义为存在未结束任务（created/running/waiting-for-user/paused/interrupted）；已完成/失败/取消仍可从托盘历史查看，不触发自动悬停。来源为本次用户变更，映射DS-S2 AC2/AC5/AC6与DS-S1忙碌不隐藏要求。

验收：空库悬停不显示；有未结束任务悬停显示；同一悬停期间任务从无到有也显示；running或准入占用进入忙碌形象，结束后恢复闲置；等待/暂停仍能打开面板但不伪装正在执行；读取失败标记未知，不播放执行动画或作为收起许可。运行任务开始后已收起小龙唤醒；拖动不误开。减少动态效果只保留静态忙碌提示。

架构：TaskHost从既有TaskStore读取未结束列表limit1，复用activity()读取运行/准入事实；Rust返回两个派生布尔值，不新增持久化/任务状态所有者。专用本地pet命令固定窗口身份，在blocking worker查询SQLite；前端只保留瞬时表现。忙碌动画复用既有呼吸/尾巴/响应变换，加明显的“忙碌”提示，不生成新素材。原生悬停维持窗口内同坐标系检测，查询周期不作为严格性能门槛。

## 同桌面与面板操作（2026-09-14用户补充）

面板与小龙必须在同一桌面/Space，同进程应用相同原生窗口集合行为；不切换到其他Space打开。鼠标从小龙跨间隙进入面板后保持，面板上的现有任务按钮可操作；离开面板与小龙区域后隐藏，跨间隙留350毫秒宽限，已经进入面板后离开立即在下次原生观察隐藏。当前只读任务按钮仍为选择详情、刷新、分页，暂停/取消未接通不得假装执行。

小龙任务表现复用assets/mascot/互动动画生命周期-v1.md：真实执行占用映射executing（认真挥爪，约1.4秒循环），等待用户映射waiting_for_user，暂停/中断映射paused，其余idle。执行优先，非执行时首个未结束任务作为代表（按任务ID）；成功/失败一次性动画仍需真实事件去重，当前快照不重播。executing使用同角色透明四帧素材，不把整张PNG变换伪装成局部挥爪。此补充覆盖此前新增文字忙碌标记的工程建议。

透明帧验证失败后改用已有透明PNG局部爪层，按生命周期文档补充设计实现executing微挥爪；完整waiting_for_user举爪、paused收翼素材尚未完成，状态切换先接通，不能宣称这些姿态已验收。

托盘为手动入口，鼠标尚未进入面板时不自动关闭，以便从菜单栏移动过去；首次进入面板后才按移出关闭规则处理。自动悬停入口跨间隙仍有短宽限。

## 人工接管记录与交回（2026-09-14用户变更）

来源：本次用户明确执行中支持人工接管并记录用户行为，作为交回Agent的Observe依据；架构Recording与桌宠/任务恢复约束，Accepted AD-TM-03。仅Agent创建任务，人工接管不创建新任务。

验收映射：TAKE-01显式接管阻止Agent新动作，停止未确认不称已移交；TAKE-02本次手动接管开启可见、可停止的记录，只录user输入，密码/安全界面/排除应用不采；TAKE-03原始时间线不可变并关联原task_id；TAKE-04交回保存证据并执行新鲜Observe，向归属Agent交付轨迹/证据引用及当前状态；TAKE-05交接失败/配额缺口明确反馈、保持暂停，不自动续跑；TAKE-06Agent重新Observe并显式恢复，重新准入后才executing。

TM-S3管接管及停止确认，RC-S1管用户记录/不可变证据，TM-S5管任务时间线引用，TM-S4管交回及显式恢复，AG管归属Agent交接协议，DS-S2展示已有任务接管/记录中/交回。自动输入干预只暂停，不无提示开启Recording；显式接管作为用户手动开始。已有每设备Recording时明确冲突，不覆盖。

UI流程：任务面板“接管”→“正在停止Agent控制/记录中”→停止确认后人工控制；小龙按既有暂停表现并保留独立录制提示。用户可以停止记录，任务仍保持人工接管；交回时如果停止后有未记录操作标注证据缺口，最终Observe仍必须新采集。“交回Agent”不等于立即继续，不用点击桌宠自动恢复任务。

协议/持久化/Driver停止与授权/隐私字段未定稿，相关Story保持设计阶段，不提前实现采集或向外发送用户记录。Windows暂缓、真实双平台证据保留。

## 进行中分页反馈（2026-09-18）

“进行中”页直接显示服务端已经筛选的 `running` 页。即使“全部”中更早的暂停、中断或取消任务超过一页，运行任务仍出现在首个进行中页；页码和项数只描述过滤后的集合，空态不得由客户端页内过滤产生。
