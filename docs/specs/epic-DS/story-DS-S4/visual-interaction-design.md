# DS-S4 视觉交互设计

## 入口与流程

用户从托盘选择“生成桌宠形象”或“导入桌宠资源包”。生成入口允许选择自定义参考图与可选性格描述，随后明确显示将把哪些文件交给哪个已连接 Agent/生成服务；用户确认前不外发。生成完成后自动进入同一导入校验流程。导入期间小龙保持当前姿态并显示简短“正在检查资源包”；成功后播放一次既有 success 反馈，再回到由真实任务派生的状态。入口不打开全屏应用，也不改变小龙的位置或任务菜单。

## 状态与错误反馈

无效文件显示“资源包不符合规范”，损坏或超限显示“资源包无法安全导入”，替换失败显示“保留当前小龙形象”。反馈不泄露用户文件路径或压缩包内容。减少动态效果时跳过过渡动画，直接切到状态静态帧。

生成不可用时显示“当前没有可用的形象生成 Agent”；未同意外发、用户取消、生成失败或单个状态未通过质检时，清楚说明未替换当前形象。生成预览必须按 Yonder 状态名称逐项展示，用户不能把“执行中”改为与任务无关的含义。

## 无障碍与平台验证

托盘入口有明确名称；文件选择取消不报告失败；成功与失败均能由辅助功能文本读取。macOS 原生验证覆盖选择、取消、成功、拒绝和重启；Windows 暂缓。
