# EN-S2 视觉交互设计

## 入口与流程

发布人员通过本地命令执行构建、签名、公证和验证。用户安装时看到系统原生安装器或应用启动流程，不出现第二个自定义更新界面。

## 状态与错误反馈

发布命令输出阶段、产物路径和结构化校验结果。签名、公证、迁移、备份或构建身份不一致时明确停止，不用成功消息掩盖失败；构建身份错误只报告产物种类与不一致分类，不输出环境变量或构建机路径。启动时只显示版本与通道，不显示内部提交或构建机信息。

安装生命周期验证只输出`fresh_install`、`upgrade`、`rollback`、`uninstall`与`user_data_preserved`等结构化布尔结果及不可逆哈希；候选校验失败时保持旧应用原位或自动恢复，并明确返回失败，不显示临时用户数据正文。卸载样本使用可恢复移动，结果同时说明应用已离开安装位置且用户数据仍保留。

## 无障碍与平台验证

安装器错误文案可被读屏软件识别。macOS 与 Windows 分别提供安装、升级、回退和卸载证据；证据不包含用户数据或日志正文。
