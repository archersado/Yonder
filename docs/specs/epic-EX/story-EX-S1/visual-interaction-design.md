# EX-S1 视觉交互设计

## 入口与流程

本 Spike 无正式桌宠 UI。探针调用方可看到样本编号、候选操作/目标编号、模型选择/置信、实际派发或拒绝、动作后 Observe 结论和交回原因；不显示或保存用户正文、截图、完整命令输出。人工触发的暂停/取消必须在探针中立刻阻止后续动作。权限拒绝、目标失效、低置信、`unknown` 和网络失败分别显示明确分类，不以「执行成功」遮盖。验证证据使用隔离应用/文档，macOS 与 Windows 各保留结构化日志；需要截图时仅用无敏感 fixture。

## 状态与错误反馈

每次决策输出样本、候选、选择、置信与结果分类；失败原因不合并为成功。

## 无障碍与平台验证

macOS 与 Windows 各保留结构化日志；需要截图时仅用无敏感 fixture。
