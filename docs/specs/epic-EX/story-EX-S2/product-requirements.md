# EX-S2 产品需求

## 问题与目标

原始需求：产品简报「MVP 主干链路」第 5～9 项及「Task Space 与权限模型」要求 Agent 发起、用户可见可控、逐任务审计；补充材料「CUA 与 BUA 的 Task Space」规定两条路径共享任务与权限。后续用户变更（2026-09-21）要求外部慢脑首规/Observe 后 replan，Jev 快脑选择执行动作，并明确慢脑链路仍从现有 Gateway 进入。2026-09-22 用户变更要求 Jev 支持配置界面。架构约束：架构主干「Agent Gateway」「任务、状态与恢复」及 AD-TM-08/13 的任务身份、动作后 Observe、同事务事件/Outbox、单租约与 `unknown`。本 Story 不改变首次计划和 replan 的外部所有权。

## 范围与非目标

范围是已验证计划片段内的本地决策、执行与交回；非目标是外部 Agent 首次计划、语义 replan、第二 Gateway 或第二任务状态机。

## 验收条件

- TARGET-ACTION-01（2026-09-30用户变更）：归属慢脑可经同一Gateway提出消息意图；接收人和正文只驻留有界内存，计划、事件、Outbox、日志和Jev只持有不透明引用。
- TARGET-ACTION-02：计划片段可分别表达聚焦目标入口、输入目标查询、激活目标、聚焦消息输入框、填写草稿与发送；每个槽位仍是一个动作，同槽位元素/坐标候选是同一步骤的替代路径。坐标只允许用于点击聚焦；固定trycua不支持坐标文本。只有Driver确认且同次Observe有效的聚焦才建立一次性焦点凭据；`unverifiable`必须交回且不得继续输入引用文本。
- TARGET-ACTION-03：Application只在派发前解析敏感文本并交给CUA Driver；元素唯一时优先执行，元素缺失/不唯一时不执行原动作并返回视觉证据。
- TARGET-ACTION-04：发送确认只有在执行到发送槽位时才出现在顶部执行浮窗；本机用户批准后一次消费，Agent不能自报确认，拒绝/过期/unknown不重试。
- TARGET-ACTION-04A：用户在顶部浮窗批准后，Yonder必须自动唤醒同一活动计划片段并继续发送槽位，不要求慢脑再次调用执行。该可信内部续跑只继承原任务归属、片段版本和当前游标，不得形成新计划、改变候选或绕过确认自身期限；结果仍须Observe，异常交回慢脑。
- TARGET-ACTION-04B：确认续跑完成片段后，Yonder必须经AG-S5当前归属会话自动唤醒慢脑执行最终目标核验；Driver成功不得直接完成任务。顶部浮窗保持到慢脑经Gateway提交终态，终态后立即消失。
- TARGET-ACTION-05：企业微信搜索入口可使用封闭`⌘F`快捷键候选；不得接收任意组合键。动作仍绑定精确窗口并强制Observe，`unverifiable`直接交回且不得建立搜索焦点凭据。
- TARGET-ACTION-06：协议1.39允许目标查询和草稿引用文本携带有限窗口坐标；Yonder必须从引用展开正文并强制精确窗口foreground原子输入。Agent不得提交正文或delivery mode，未确认或Observe失败不得推进。

| EX2-20 | 2026-10-08 用户变更；AD-AG-09/AD-CU-10 | 快脑选择必须来自新鲜 AX/UIA Observe 自然形成的元素动作空间，不得为测试或强制启用 Jev 构造无业务意义的恢复路径。唯一合法元素直接执行；多元素时 Jev 只接收步骤语义、封闭角色和脱敏短标签，Application 注入同次临时句柄并在 Driver 侧复核新鲜度。 |
| EX2-21 | 2026-10-08 用户变更；AD-EX-05/AD-TM-24 | Driver 强制 Observe 后，Jev 快脑可依据当前步骤、封闭动作语义、结构事实和本轮有界脱敏观察摘要判断步骤 `complete / incomplete / uncertain`。只有高置信 complete 推进槽位；其他结论交回慢脑。快脑不得据此完成用户任务，最终目标仍由归属慢脑经 Gateway 核验。 |
| EX2-22 | 2026-10-08 真实 QQ 音乐回归；AD-EX-05 | Jev 从新鲜 AX/UIA 候选选择控件时必须同时接收用户可见任务整体目标、完整片段步骤标签、当前步骤序号和当前步骤标签；不得只用局部步骤或扁平候选。上下文有界、脱敏、只驻留内存，不包含任务说明、正文、坐标或历史 Payload；整体目标缺失时不得调用 Jev。 |
| EX2-23 | 2026-10-09 用户变更；AD-EX-03 | Jev 模型标识必须在独立设置面板配置并随 Application 配置快照传给候选选择和步骤核验；本地模式允许经校验的 HTTP/HTTPS base URL，远端模式仍只允许 TypeSafe HTTPS。Adapter/Worker 不得硬编码或覆盖模型名，既有配置须安全兼容。 |
| EX2-24 | 2026-10-09 用户变更；AD-EX-03 | Jev 置信度字段必须是可填写的响应顶层属性名，而非固定枚举；未填写时使用 `confidence`。阈值 `0..1` 随同一配置快照应用于候选选择和步骤核验。既有 `confidence_metric` JSON 须兼容迁移；已配置字段缺失、非有限或越界时必须交回慢脑，不得自动探测其他属性。 |
| EX2-25 | 2026-10-09 multilingual 真实回归；AD-EX-05 | AX/UIA 自然候选须覆盖 Driver 可操作的文本框与组合框；超过候选上限时按任务目标和当前步骤对脱敏标签作支持 CJK/拉丁文本的稳定相关性排序后截断，不得因树前序让目标控件永远无法进入快脑候选。 |
| EX2-26 | 2026-10-09 multilingual 原始响应对照；AD-EX-05 | 自然元素候选交给 Jev 时须使用由脱敏标签派生的短生命周期语义别名，不能把 `ax-element-<index>` 等 Driver 句柄直接作为模型选项。Application 必须维护别名到同次新鲜句柄的内存映射、拒绝未知或重复返回，并只把已选别名映射回原候选；别名和映射不得持久化。 |
| EX2-27 | 2026-10-18 终局状态回归 | 若首次终局核验唤醒因 Connector 不兼容或断开而未送达，支持协议1.53的同一归属Connector重连时须从Store与Execution Runtime新鲜事实恢复并重投一次；不得自动完成任务或依赖UI投影判断。 |

## 待审建议

计划片段最小字段、步数/时间/token 预算和低置信阈值在 EX-S1 之后定稿；用户配置只是全局上限，实际片段始终取计划授权值与全局上限的较小值。首版不在界面或 Jev 配置中持久化 API Key、模型提示词、命令参数或候选规则；仅持久化受限模型标识。面板非空凭据输入只直写 macOS 系统凭据入口，Windows 后补。首版不设计通用工作流语言或第二套任务状态机。
