# EX-S2 视觉交互设计

## 入口与流程

入口仍是 Agent 创建的现有任务，不提供用户手动创建计划。桌宠沿用轻量形象与悬停任务菜单，执行中展示忙碌动画；任务详情仅增加能让用户判断当前归属的状态：本地执行中、等待 Agent 重新规划、等待用户确认/接管、结果待核实。若多个任务并行，每张任务卡显示各自状态；前台桌面租约只允许一项 CUA 操作。

## 状态与错误反馈

计划片段执行时，用户按「取消」或「接管」立即显示正在停止后续动作，随后按既有停止确认结果展示已暂停/已取消或 `unknown` 待核实。低置信或计划偏离显示简短原因并保持任务可查看；不弹出快脑内部候选概率面板。键盘与无障碍可访问现有任务卡操作，状态变化通过文字和可读状态通知，不只靠动画。该完整执行体验须以 Windows/macOS 各自真实任务验证；当前 macOS-only 决策子路线不改变任务界面或状态。

不向用户展示 Recipe、内部决策链路或原始模型请求；可见状态只保留任务、控制与最小原因。

## 无障碍与平台验证

「Jev 快脑设置」从系统托盘菜单打开独立设置窗口，不嵌入任务总览。首版只包含启用开关、服务形态与端点、每片段步数/时间/token 上限、四类执行层上限。保存前逐项校验并禁用提交；保存后显示「已启用」「未配置」「配置无效」和不可用原因，不把保存成功等同模型可用。置信阈值、强制 Observe、敏感操作确认和交回规则以只读安全说明展示，用户不能降低。运行中的片段在任务详情显示「当前片段使用已保存配置」；修改配置不热替换该片段，但关闭启用后立即显示「正在交回 Agent」。所有控件可键盘操作，错误使用文字说明；不弹出内部候选概率面板。

2026-09-24 用户变更后，设置窗口增加 API Key 密码框与“已配置/未配置”文字状态。已配置时仍为空白且不可复制；空字段保存只更新非敏感配置，非空字段才替换 Keychain 凭据。若凭据缺失、模型不可用或候选交回，任务侧复用现有文字状态和错误反馈，不新增 `thinking` 状态。
