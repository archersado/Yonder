# EX-S2 视觉交互设计

## 入口与流程

入口仍是 Agent 创建的现有任务，不提供用户手动创建计划。桌宠沿用轻量形象与悬停任务菜单，执行中展示忙碌动画；任务详情仅增加能让用户判断当前归属的状态：本地执行中、等待 Agent 重新规划、等待用户确认/接管、结果待核实。若多个任务并行，每张任务卡显示各自状态；前台桌面租约只允许一项 CUA 操作。

## 状态与错误反馈

用户按「取消」或「接管」时立即显示正在停止后续动作，随后按既有停止确认结果展示已暂停/已取消或 `unknown` 待核实。低置信或计划偏离显示简短原因并保持任务可查看；不弹出快脑内部候选概率面板。键盘与无障碍可访问现有任务卡操作，状态变化通过文字和可读状态通知，不只靠动画。Windows/macOS 各用真实任务验证可见状态及控制反馈。

## 无障碍与平台验证

「Jev 快脑设置」从系统托盘菜单打开独立设置窗口，不嵌入任务总览。首版只包含启用开关、服务形态与端点、每片段步数/时间/token 上限、四类执行层上限。保存前逐项校验并禁用提交；保存后显示「已启用」「未配置」「配置无效」和不可用原因，不把保存成功等同模型可用。置信阈值、强制 Observe、敏感操作确认和交回规则以只读安全说明展示，用户不能降低。运行中的片段在任务详情显示「当前片段使用已保存配置」；修改配置不热替换该片段，但关闭启用后立即显示「正在交回 Agent」。所有控件可键盘操作，错误使用文字说明；不弹出内部候选概率面板。
