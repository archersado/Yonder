# EX-S3 视觉交互设计

## 入口与流程

用户仍从小龙的悬停任务菜单查看 CUA/BUA 任务；忙碌动画对应实际执行，不因 Jev 正在推断却未获执行许可就伪报动作已发生。CUA 用户触碰桌面时进入暂停/接管反馈；浏览器任务接管仍打开 ego-lite 对应任务，不在 Yonder 复制浏览器面板。目标失效或页面变化时任务显示「正在重新观察」或「等待 Agent 重新规划」，避免持续转圈。取消与接管按钮保持可键盘操作，状态有文字与无障碍名称。Windows/macOS 原生验证分别检查显示、焦点和停止反馈。

## 状态与错误反馈

目标失效、页面变化和用户干预分别显示重新观察、交回或暂停原因，不以动画代替状态。

## 无障碍与平台验证

取消与接管按钮可键盘操作，状态有文字与可读名称；Windows/macOS 分别检查显示、焦点和停止反馈。
