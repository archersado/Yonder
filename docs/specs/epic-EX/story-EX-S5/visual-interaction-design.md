# EX-S5 视觉与调用方交互设计

## 顶部执行浮窗

handback 后维持既有顶部浮窗，不新增弹窗。召回阶段使用当前步骤区域的短状态：

- `正在召回已验证经验…`
- 命中后：`已召回执行经验，慢脑正在重新规划`
- 未命中或读取失败：`无可用经验，慢脑正在重新规划`

不展示经验正文、应用内文本、成功率、模型原文或思维链。召回不得使浮窗从执行/交回状态闪回空闲。

## 慢脑输入

既有 `source=replan` 输入增加“历史经验提示”分段，每条只包含策略、适用前置和必须重新验证的成功条件。分段明确声明：提示不是当前事实；先调用 `task.get`、`task.events`，再决定新计划；`unknown` 副作用不得自动重试。

空结果时仍立即投递原 replan 文本。输入通道不可用时沿用既有明确错误和浮窗状态，不因经验召回产生第二种连接状态。
