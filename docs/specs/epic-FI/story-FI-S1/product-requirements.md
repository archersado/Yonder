# FI-S1 产品需求

## 问题与目标

绝对路径防穿越，别名不能绕过同文件互斥，删除默认回收站。

## 范围与非目标

本 Story 仅负责“规范文件身份与受控操作”。首批实现 macOS File Port/Adapter、任务绑定临时授权以及可信原生选择入口；Windows 按用户决定延期并明确 unavailable。当前产品入口只让 Agent 看见安全授权引用，不在本增量开放文件副作用执行。

## 验收条件

- FI-01：目标行为有可复现成功样本，失败不得伪报成功。
- FI-02：输入只接受规范化绝对路径；未创建输出通过既有父目录验证授权根，阻止路径穿越和链接逃逸。
- FI-03：软链接、硬链接、大小写别名和重命名不能绕过同文件写互斥。
- FI-04：写入使用同目录临时文件，校验后原子提交；冲突或失败不留下正式目标。
- FI-05：Office/WPS已打开文件不得被绕过锁覆盖；锁冲突返回可观察等待原因。
- FI-06：删除默认进入系统回收站；永久删除不在MVP默认入口。
- 平台限制与未实现项明确；涉及 UI/Driver/权限时分别提交 Windows/macOS 原生证据。

## 原生授权入口与 Gateway 可见性（2026-09-25）

- FI-ENTRY-01：Task Space 只提交任务与用途，文件路径必须来自 Tauri 命令内部的系统原生选择器；授权根只能由所选目标父目录派生。
- FI-ENTRY-02：读取与新建由一次明确选择签发；替换与移入回收站在选择后须原生二次确认。取消选择或确认不得产生授权。
- FI-ENTRY-03：协议 1.27 只向已认证归属 Agent 返回当前任务授权的 `grant_id`、用途和到期时间；不得返回路径、授权根、身份、哈希或正文，读取列表不得消费一次性引用。
- FI-ENTRY-04：本机用户可查看并撤销当前任务授权；Agent 禁用或撤权必须撤销其全部授权并断开会话。
- FI-ENTRY-05：任务失效、非归属 Agent、协议过旧、授权到期、容量不足或平台不可用均失败关闭，不自动重弹选择器或扩大范围。
- FI-ENTRY-06：本增量不开放文件读取、写入、覆盖或删除执行；Windows 入口保持 unavailable 并明确延期。

## 待决事项

Windows 文件身份、Office/WPS 锁与原生选择器实机证据，以及使用授权引用的 Agent 文件执行和任务事件接线仍待后续增量。

## 临时文件授权引用核心（2026-09-25）

- FI-GRANT-01：文件路径、授权根或 Agent 自报确认不能直接取得文件能力；只有可信 LocalUser 入口可为当前任务签发引用。
- FI-GRANT-02：引用绑定任务、归属 Agent、用途、精确文件身份/目标父目录和最长 15 分钟有效期；跨任务、跨 Agent、用途变化、过期或撤销均拒绝。
- FI-GRANT-03：读取授权有效期内可复用；新建、替换和回收站授权首次解析即消费，unknown 也不能自动重放。
- FI-GRANT-04：既有文件保存身份与 SHA-256 而不保存正文；新建目标先规范化父目录、验证授权根和不存在性，执行时仍由 File Port 重新检查竞态与锁。
- FI-GRANT-05：授权只驻留内存，重启不恢复；满额失败关闭，不把有效授权静默淘汰。产品选择器与 Gateway 接线另行实施。

## macOS Runtime 增量（2026-09-25）

来源：FI-01～06、Accepted AD-FI-01 与 macOS/WPS Spike。

- FI-RUNTIME-01：既有文件经规范路径、软链接或硬链接访问时归并到相同 `st_dev + st_ino` 身份；所有路径必须位于规范化授权根内。
- FI-RUNTIME-02：读取最多 16 MiB，并返回稳定身份和 SHA-256；读取过程中身份或大小变化不得返回伪稳定快照。
- FI-RUNTIME-03：新建必须目标不存在；替换必须同时匹配预期身份与 SHA-256。写入在同目录独占临时文件中完成，调用方校验、文件同步、原子替换及父目录同步后才返回成功。
- FI-RUNTIME-04：同文件写租约与宿主 advisory lock 任一冲突均拒绝；失败清理临时文件，提交结果不明不自动重试。
- FI-RUNTIME-05：删除仅可信 LocalUser 可调用，并通过 macOS 系统回收站；Agent 不能自报确认，永久删除没有入口。
- FI-RUNTIME-06：非 macOS 构建只返回 unavailable，不使用路径字符串锁、直接删除或非原子复制兜底。
