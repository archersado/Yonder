# FI-S1 视觉交互设计

## 入口与流程

默认另存；覆盖与删除需可信本地确认，Agent字段不能自报确认。冲突明确区分路径越界、同文件占用、Office/WPS锁定、目标已存在和提交未知；用户文件不在自动验证中被修改。

## 状态与错误反馈

呈现真实可观察状态；加载、等待、失败和未提供能力不能伪装为完成。无独立界面时由调用方界面或结构化响应承载，不额外建立窗口。

## 无障碍与平台验证

有 UI 的按钮提供名称与可见焦点，支持键盘，减少动态效果遵循系统偏好；无 UI 时保证调用错误稳定可区分。原生交互须各平台独立证据。

## 待决事项

双平台身份语义、原子写与锁冲突需设计和验证。
