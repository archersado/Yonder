# RC-S2 视觉交互设计

## 入口与流程

用户界面使用“操作示教”和“回放流程”，不使用“RPA录屏”或“宏”。录制入口属于RC-S1；停止录制后才出现“整理为流程”。流程库从小龙轻量菜单进入，不要求切换成独立全屏模式。

## 审阅流程

停止录制后显示步骤列表，每步包含序号、动作名称、目标应用/控件摘要、参数状态、预期结果和隐私/完整性标记。用户可以：

- 删除不需要的步骤；
- 上下调整顺序；
- 编辑允许的参数或补充文本占位值；
- 查看动作前后有限证据，但不默认展开敏感截图；
- 保存为具名的新版本，或取消并保留原始Recording。

存在gap、隐私排除、目标不稳定或参数缺失时，在对应步骤原位说明，保存按钮显示“保存草稿”；不能用绿色完成态掩盖不可回放。

## 回放流程

用户选择流程后先显示完整步骤、将控制的应用和风险摘要；点击“请求回放”后等待Agent创建任务。准入成功才显示3秒倒计时，倒计时提供“取消”。

执行时小龙使用既有`executing`动作，轻量进度卡显示当前步骤、总步数、“暂停”和“取消”。Esc和用户真实键鼠输入立即请求暂停；暂停后显示最后一次Observe结果，由Agent决定恢复、修改或结束。

## 状态与错误反馈

### 流程库

列表显示名称、版本、更新时间、步骤数和`草稿|可回放|需修复`状态。支持打开、复制为新版本、请求回放和删除派生流程。删除需确认，且明确“不删除原始录制与既有任务审计”。

## 无障碍与平台验证

步骤排序同时提供键盘“上移/下移”，拖拽不是唯一方式；风险与状态有文字，颜色不是唯一信号。减少动态效果时倒计时与步骤切换不使用大幅动画。Windows/macOS分别验证键盘、屏幕阅读器、不同DPI/显示器、停止入口和桌宠状态一致性。
