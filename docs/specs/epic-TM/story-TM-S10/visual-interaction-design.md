# TM-S10 视觉交互设计

## 入口与流程

任务详情基础字段新增三行：

- “任务输入”：归属 Agent 提交的有界输入摘要；旧任务显示“旧任务未声明”。
- “预期输出”：任务分配时冻结的有界输出摘要；旧任务显示“旧任务未声明”。
- “Agent 交付摘要”：通过完成门禁后提交的摘要；未完成或旧任务显示“尚未提交”。

三行随核心详情立即显示，不等待时间线或产物分页。交付摘要旁不显示“已验证”图标；目标核验和用户确认仍使用既有独立字段。产物继续使用不可变清单区块显示 opaque 引用与可用性，不展示路径或完整内容。超长内容由协议拒绝，不在 UI 截取完整 Payload 后再隐藏。

## 状态与错误反馈

缺失契约显示旧任务缺失态，尚未完成显示尚未提交；读取失败不伪装为空。产物失败保持交付摘要和核心详情。

## 无障碍与平台验证

读取失败只影响对应区块；所有内容通过 `textContent` 渲染并支持键盘/辅助技术。
