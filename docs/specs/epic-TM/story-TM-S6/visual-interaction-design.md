# TM-S6 视觉交互设计

## 入口与流程

本项无新增可见入口。可信宿主调用 Application 一次查询；没有分页、当前任务选择或 Agent 筛选参数。后续 DS 消费前需完成收起与执行准入同步设计。

## 状态与错误反馈

Running 表示数据库有运行任务；Unknown 表示当前无法确认；两者都不能据此隐藏。NoRunningTask 仅表示本次读取未发现运行任务，也不能单独触发隐藏。等待、暂停和执行器占用不能从这一结果反推；不展示其他 Agent 详情。

## 无障碍与平台验证

本项不增加控件、焦点或动画，故没有新增键盘操作。后续宿主接线必须提供可访问的状态反馈及 Windows/macOS 原生证据；本项只验核心库并如实记录平台范围。

## 汇总反馈

后续宿主使用 Busy / NoKnownWork / Unknown，Busy 和 Unknown 阻止收起。NoKnownWork 只表示本轮两个来源都未观察到工作；不得单独触发隐藏。初始化未完成保持 Unknown，不用空准入实例或 UI 空页代替。此轮无可见 UI 改动。

## 收起与新任务的协调契约

未来宿主：三分钟闲置→预约→数据库核对→收起，持有凭证直到展开成功。新任务因 PresentationBusy 暂未准入时先展开，再解除预约并进行首次准入；窗口失败保持阻断并给用户可重试反馈，不标任务执行失败。尚未实现此可见流程，本轮只验证协调核心。
