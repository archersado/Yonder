# TM-S7 视觉交互设计

## 入口与流程

任务创建后显示“已创建，尚未执行”。首次能力派发的事务提交后，Task Space 与桌宠显示“执行中”；不能以 Agent 的自然语言意图或本地临时动画提前切换。Document 和 Command 未可用时，调用方收到稳定的不可用说明，任务保持 `created`。

## 状态与错误反馈

执行中展示能力类型和当前步骤标签，不展示敏感正文或完整命令输出。启动被拒绝、文件锁、权限确认、资源冲突、Observe 失败和 unknown 分别可辨。用户输入导致暂停/中断时，立即停止执行中表现并显示“已暂停，等待重新观察”，不显示成功。

## 无障碍与平台验证

状态不能只靠动画或颜色表达；辅助技术读取任务状态、步骤与错误。CUA/BUA/Document/Command 的真实状态变化在 Windows 与 macOS 分别提供截图、视频或结构化日志；尚未获得能力的系统明确标记为未验证。
