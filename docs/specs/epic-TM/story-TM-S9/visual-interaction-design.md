# TM-S9 视觉与交互设计

## 入口与流程

不新增主窗口。顶部任务控制条、桌宠和 Task Space 订阅同一运行时投影，立即显示当前步骤、已完成 ✓、待核实 !、HandBack，不轮询 SQLite 判断执行状态。

## 状态与错误反馈

短暂持久化落后不打断动作；达到硬限时显示“执行记录积压，已在下一步前暂停”，并保留取消/接管入口。状态必须有 AX 文案，不只依靠颜色。SQLite 投影失败不得把正在执行显示为空闲。

任务列表、首页最新任务和顶部控制条必须对同一活动任务显示一致状态。已在 Runtime 取消、暂停或终结的任务不得因 SQLite checkpoint 暂时落后继续显示“执行中”；列表筛选也必须使用覆盖后的状态，不能先按旧状态保留错误条目。

终态异步投影重试期间，界面继续显示 Runtime 的真实终态，不回退为“执行中”。若持久化超过有界健康期限，诊断只显示“执行记录待同步”，不得暴露任务正文、动作参数或完整 Payload，也不得阻塞取消、接管或任务响应。

## 无障碍与平台验证

所有运行态、完成、待核实、HandBack、持久化背压与控制结果都必须提供可读 AX 文案。macOS 使用正式 Desktop 组合根、Gateway 和顶部控制条验证；Windows 按当前决定暂缓，不外推双平台结论。
