# VI-S1 视觉交互设计

## 入口与流程

Windows/macOS统一使用“语音输入”名称和麦克风图标，不叫“语音模式”。用户启动后，小龙切换语音专用的`voice_listening`表现：一只爪子贴近耳侧、头部轻微朝爪子侧倾，并保留呼吸与眨眼；不得显示任务“收到请求”的✓或完成庆祝动作。旁边出现轻量收音条：音量波形、实时文字、停止和取消，并提示“说完短暂停顿后自动发送整段”。检测到有效语音后的短暂停顿或手动停止会结束本轮；等待最终转写时显示“正在整理语音”，投递时显示“正在发送给智能体”，成功后自动收起。没有独立“提交”按钮，也不在每句停顿后继续收音。

用户点击语音入口即明确授权本轮最终非空文字自动投递，不再二次确认。最终结果产生前关闭面板或按Esc等同取消，不残留后台收音；交付失败时保留文字并显示“重试”和“取消”，不自动重试。
初始静音或空结果只显示“未识别到可发送的语音”，不得显示发送成功；没有可接收输入的Agent时明确提示连接问题，不能把“重新开始”描述为重新发送上一段。

## 状态与错误反馈

- 请求权限：说明“用于把本次语音转成文字”，提供对应系统设置入口。
- 正在聆听：持续显示麦克风启用标记和可感知音量反馈。
- 正在转写：显示部分结果但标明尚未完成。
- 正在发送：最终文字只读，显示目标Agent名称和发送进度。
- 发送失败：保留本次文字，提供重试或取消。
- 失败：在原位说明权限、设备、网络或服务原因，并提供重试或取消。

## 无障碍与平台验证

所有操作可键盘访问并有可读名称；波形不是唯一状态信号。减少动态效果时使用静态电平和`正在聆听`文字。屏幕阅读器不得朗读每个部分转写增量，只播报状态和最终结果。

### 平台验证

macOS与Windows分别提供真实麦克风、权限拒绝/撤销、Esc取消、设备切换和停止后系统录音指示消失的截图或结构化证据。
