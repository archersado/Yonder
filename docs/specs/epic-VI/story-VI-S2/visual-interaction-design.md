# VI-S2 视觉交互设计

## 入口与流程

Windows/macOS统一使用“会议伴听”作为入口。点击后先展示本次将采集的“我的麦克风”和“系统声音”，用户确认后开始。面板顶部始终保留两路开关和“停止伴听”；正文按时间顺序显示来源与转写。

小龙使用既有`listening`形象，并显示持续可读的REC标记。面板收起后，小龙旁保留“伴听中”胶囊和停止按钮；切屏或隐藏桌宠不能让采集状态不可见。

## 状态与错误反馈

- 启动中：逐路显示权限和设备初始化状态。
- 伴听中：显示每路音量、开关和最新一句文字。
- 无信号：指出具体音源，不把静音显示为正常转写。
- 不完整：网络、设备或权限中断后保留已转写内容并标注缺口。
- 已停止：提供“导出记录”“请求整理纪要”“关闭”。

## 无障碍与平台验证

开始采集、保存文件和把转写发送给Agent分别确认，不能用一次授权永久替代。颜色、波形和头像不能作为唯一来源标识；所有音源、说话人和按钮都有文字名称与键盘焦点。

### 平台验证

Windows/macOS分别记录双路启动、单路暂停、权限拒绝、设备切换、收起后停止入口及退出清理证据；平台文案使用对应系统术语。
