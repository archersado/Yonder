# VI-S3 视觉与交互设计

## 入口与流程

设置中的“语音回复”开关由用户显式开启，默认关闭。支持语音回复的 Agent 返回内容时，现有回复卡继续显示文字，并在卡片标题区提供播放状态和“停止”按钮；不打开新的全屏页面，也不把播放控制埋入任务详情。

## 状态与错误反馈

- 准备首句：显示“正在准备语音”，文字流不等待 TTS。
- 播放中：显示“正在朗读”及停止按钮；可用轻量音量指示，但波形不是唯一状态信号。
- 回复文字完成但仍在播放：保留“回复已完成 · 正在朗读”，避免把文本终态误认为播放终态。
- 用户停止或开始收音：立即显示“已停止朗读”；不显示 Agent turn 已取消。
- 本地声音缺失或 TTS 失败：显示“本地语音不可用，已保留文字回复”，不得反复弹窗或静默联网。

关闭回复卡视为停止本轮语音并清理音频。关闭语音回复总开关同样停止当前播放，但不删除仍在卡片中的文字。

## 形象与顶部浮窗

语音回复不是任务执行步骤，顶部执行浮窗不展示 TTS 队列、句子正文或声音信息。首版不新增第十种任务形象状态；如果后续接嘴型，只允许播放期间叠加不携带业务语义的振幅动画，任务的 executing、waiting、paused、success、failed 等可信状态保持可辨。

## 无障碍与平台验证

- 开关和停止按钮必须可聚焦、有稳定中文可读名称，并支持 Space/Enter。
- TTS 开启时，回复正文区域不自动触发屏幕阅读器整段朗读，避免双声道重复；用户主动浏览正文仍保持可访问。
- 减少动态效果关闭音量动画但不关闭音频；系统静音不伪装为播放成功。
- Windows/macOS 原生验证分别覆盖开启、连续播放、停止、收音打断、缺失声音、离线、键盘和屏幕阅读器行为，并提交结构化日志及可见证据。
