# 设计

Spike位于独立目录并保持单进程。客户端只主动连接公开测试WSS，发送固定非敏感标记并配置有界帧；有效证书回显端点与无效证书端点分别验证系统TLS路径。停止信号必须关闭连接与重连计时器，公开测试服务不可用时样本明确失败。

重连延迟候选为有上限的指数退避并加入抖动；统一样本记录尝试次数、延迟范围、TLS结果、关闭结果和残留任务数，不记录凭据或正文。具体常量由双平台样本校准，不能直接成为产品默认值。

外部平台配对、生产认证、Credential Store、Outbox补传和Desktop组合根不在本Change。若macOS候选通过而Windows暂缓，只记录子范围证据，AD继续Proposed。
