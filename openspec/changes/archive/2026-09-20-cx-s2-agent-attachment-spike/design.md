# 设计

Spike只使用Python标准库和内存字节，模拟既有64 KiB有界帧。发送方声明附件标识、MIME、总字节数与SHA-256，再按序发送可放入单帧的base64分块；接收方按当前会话、序号、总量和哈希验证，完整后才允许同会话输入引用。

统一样本覆盖1字节、跨分块、4 MiB边界、超限、乱序、哈希错误、其他会话引用、deadline和断连。失败清理只作用于所属会话；其他会话引用既不能读取，也不能删除原会话附件。原会话结束后检查接收缓冲为0。证据只写结构化计数、布尔值和错误分类，不写图片、base64、正文或哈希。

本Change不决定最终线协议方法名，不接产品UDS/WSS，不修改`MAX_REQUEST_BYTES`。若样本需扩大单帧、使用本机路径、持久化字节或不能在失败后清零，则拒绝候选并回到Architecture Decision。
