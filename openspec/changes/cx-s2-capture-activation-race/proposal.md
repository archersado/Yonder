# Proposal：CX-S2 截图隐藏激活竞态修复

## 背景

macOS 正式包在用户完成有效圈选后会先隐藏覆盖窗口，再调用 ScreenCaptureKit。隐藏窗口会使原来源应用重新成为前台应用；现有应用切换监听器把这次产品内部、可预期的激活变化误判成用户切换应用，提前清除了 `PreviewSession`，导致截图与确认卡消失。

既有已归档的应用切换清场规格已经明确：截图主动隐藏期间不得清除正在捕获的会话。本 Change 只修复实现回归，不扩大截图、协议、持久化或权限边界。

## 范围

- macOS 应用切换回调在 `Capturing` 阶段忽略由截图主动隐藏造成的激活变化。
- `Selecting`、`Reviewing` 等可见阶段继续执行应用切换清场。
- 增加阶段判断回归测试，并用正式 GUI 包验证有效圈选后出现内存截图预览。

## 非目标

- 不自动修改系统屏幕录制权限。
- 不增加截图持久化、日志或任务事件。
- 不改变 Windows、多显示器和运行中撤权的既有 Deferred 范围。
