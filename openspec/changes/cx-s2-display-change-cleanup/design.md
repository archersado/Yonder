# 设计

macOS Adapter在AppKit主线程注册屏幕参数通知，并复用既有共享清场函数。观察者只在圈选层或确认卡可见期间存在；清场、发送、打开失败和原生关闭都会注销它。Application仍是会话、语音和附件清场的唯一所有者。

分辨率变化可能同时触发原生`CloseRequested`或应用切换通知；这些路径与屏幕通知最终进入同一清场不变量，允许实际清理原因竞争，但不得残留截图、选区、笔画或语音。

验证使用公开`CGDisplaySetDisplayMode`临时切换主显示器模式并立即恢复：确认卡必须关闭，隐藏窗口标题必须记录清理原因和零资源状态，且不保存截图、问题或语音正文。
