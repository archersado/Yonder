# Region Preview Delta

## ADDED Requirements

### Requirement: 显示器参数变化必须结束可见圈选会话

系统 MUST 在macOS可见圈选层或确认卡存在期间订阅屏幕参数变化通知，并在变化后复用统一清场路径。

#### Scenario: 选择中显示器参数变化

- **WHEN** 圈选层可见且主显示器模式、分辨率或屏幕布局变化
- **THEN** 系统取消本轮语音、清除临时选区、笔画和截图并隐藏圈选窗口
- **AND** 不发送Agent输入或创建任务

#### Scenario: 确认卡中显示器参数变化

- **WHEN** 确认卡可见且主显示器模式、分辨率或屏幕布局变化
- **THEN** 系统清除问题、来源应用和临时截图并隐藏确认卡
- **AND** 清场结果记录零资源状态和有界清理原因

#### Scenario: 清场与观察者生命周期

- **WHEN** 圈选会话已清场、提交或打开失败
- **THEN** 系统注销屏幕参数观察者
- **AND** 不保留跨会话监听、截图或语音状态
