# 任务卡片操作

## ADDED Requirements

### Requirement: 直接操作
系统 MUST 在每张任务卡片提供接管与取消任务，且详情按钮与操作按钮为兄弟元素不嵌套；created任务取消可用，其他状态必须禁用并说明原因。请求中必须禁用重复提交，失败可见，取消后全部历史保留。系统 MUST NOT 提供同义删除或清理按钮。

#### Scenario: 取消已创建任务

- **WHEN** created任务卡片显示“取消任务”且用户点击
- **THEN** 系统复用同一取消任务用例并保留任务、事件、说明和Outbox历史
- **AND** 不提供同义删除或清理按钮

#### Scenario: 请求失败可见

- **WHEN** 用户提交取消或接管请求失败
- **THEN** 系统保持卡片可操作并显示错误
- **AND** 不删除任务或伪造控制结果

### Requirement: 接管门禁
系统 MUST 只对执行中任务提供接管；停止确认与定位完成后才可显示接管结果。Recording未接通时 MUST NOT 启动录制或伪报已接管。键盘焦点 MUST 支持兄弟按钮互不触发其他任务或详情。

#### Scenario: 执行中任务接管

- **WHEN** running任务在安全边界后用户点击“接管”
- **THEN** 系统提交停止事实、释放该任务执行占用并进入定位流程
- **AND** 定位成功后显示“已接管”，失败保持paused并提示人工定位

#### Scenario: Recording门禁未满足

- **WHEN** 接管或定位流程尚未满足Recording前置
- **THEN** 系统不启动录制、不伪造录制状态
- **AND** 卡片保持明确的门禁原因
