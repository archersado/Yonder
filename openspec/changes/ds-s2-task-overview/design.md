# 设计

菜单关闭统一调用原生task_menu_close，仅允许task-space本地窗口；按钮和Escape共用，不由前端传目标窗口label。失焦隐藏仍归宿主。关闭/打开均由原生管理，未通过原生关闭样本不得标为成功。

最新自然交互：清醒轻点/Enter/Space保留反馈并打开任务menu；拖动仅移动，开始时隐藏menu；休眠点击仅唤醒。菜单失焦/Escape/关闭隐藏，无额外任务按钮。功能打开不依赖动画active条件，系统减少动态效果只抑制动作，不抑制功能。

最新入口修订：按用户变更和AD-DS-01，小龙与轻量任务menu同一正式宿主，menu默认隐藏、无装饰透明辅助窗口，任务按钮请求Rust定位后显示；同屏工作区夹入/上下翻转。复用现有小龙资产、动画和拖动；无外部执行入口，停靠前在TaskHost锁内重新读取活动状态，busy/unknown拒绝。完整执行收起预约仍为后续门禁，不开放执行器。

2026-09-16执行展示修正：本地Gateway同步执行会在调用期持有`TaskHost`锁，桌宠不得等待同一锁或轮询数据库后才得知忙碌。产品UDS在取得宿主锁前用Rust协议解码识别执行请求并向pet发布`executing`窗口事件；调用退出及其他任务提交后，在锁内派生下一真实展示并发布。前端仅启动读取一次快照，随后消费事件；`listening`仅使用一次性到期事件。通知不成为任务事实、不改变事务与协议。

GUI定稿：520×440辅助窗口，托盘打开/聚焦，关闭与Escape隐藏；真实目录用Tauri app_data_dir。主机打开失败在窗口显示存储不可用；查询通过task_query仅允许task-space窗口，Rust串行调用TaskHost并编码原有Response为字符串。浏览器预览无native桥显示能力未提供，测试夹具只在测试脚本注入，不包含产品演示任务。请求/详情使用旧轮次序号丢弃迟到结果；分页每次只显示一页，通过下一页访问全部，刷新和筛选重置第一页。

宿主核心分步：可信调用方传绝对应用数据目录，拒绝相对路径及固定文件名的符号链接；持有host.lock标准文件锁至宿主退出，不删除锁文件，崩溃由OS释放。打开tasks.db后循环有界恢复running至0，然后创建唯一Admission；任一步失败不返回宿主。查询固定可信LocalUser("desktop")，不暴露选择身份的参数，通过Application已有协议编码返回；不开放HTTP/IPC或接受Agent连接。具体GUI只读命令另行绑定可信task-space窗口，未实施前不声称真实Task Space可见。

桌面组合根绑定可信本机身份，调用Application已有list/get，返回由Rust唯一类型生成的结果。前端仅持选中ID、当前展示页、加载/错误状态；不推进任务状态、不从显示页决定忙碌。TaskSnapshot只使用task_id、owner_agent_id、status、sequence；不新造字段。

进行中使用include_finished=false取得未结束页后，只展示状态严格为`running`的任务；全部使用true并展示所有返回状态，limit受既有1–100约束。游标仍按服务端原页推进，刷新从第一页替换，不把不同轮次页链混成快照。无全局sequence；同任务更新才比较sequence。异步旧请求不能覆盖新选择/刷新结果。

轻量辅助面板提供刷新、关闭、列表、详情，支持Tab与Escape，不提供全屏形态。能力未接通明确显示未提供；读取失败不转为空列表。已有快照读取失败时保留并标记过期。任务ID及Agent文字安全呈现，不作为HTML执行。缺失原因、来源、步骤及外部引用明确未提供，不用状态猜测。

入口尚须定稿，不借此实施暂停的DS-S3。依Accepted AD-ST-01，MVP使用显式未加密SQLite，不调用Credential Store，不自动改写旧加密库。真实源尚不可用时不冒充真实任务数据。后续实现放入目标桌面Workspace并遵守依赖方向，不复制Application状态机到UI。加密与迁移延期MVP之后。

## 悬停入口变更（2026-09-14）

后续用户明确改为悬停小龙显示任务菜单，不再由点击打开。清醒小龙连续悬停200毫秒后显示贴身菜单；快速经过和开始拖动取消待打开。轻点仅动作反馈，休眠双眼轻点只唤醒。Enter/Space保留键盘菜单入口。悬停显示不请求原生焦点，当前应用可继续输入；进入菜单后可操作关闭，菜单失焦后隐藏。菜单不随离开小龙立即消失，以便跨越间隙进入菜单。

## 有任务才显示与忙碌形象（2026-09-14用户变更）

用户再次指出悬停未显示，并明确要求无任务不弹面板、有任务运行时显示忙碌动画。此处“有任务”定义为存在未结束任务（created/running/waiting-for-user/paused/interrupted）；已完成/失败/取消仍可从托盘历史查看，不触发自动悬停。来源为本次用户变更，映射DS-S2 AC2/AC5/AC6与DS-S1忙碌不隐藏要求。

验收：空库悬停不显示；有未结束任务悬停显示；同一悬停期间任务从无到有也显示；running或准入占用进入忙碌形象，结束后恢复闲置；等待/暂停仍能打开面板但不伪装正在执行；读取失败标记未知，不播放执行动画或作为收起许可。运行任务开始后已收起小龙唤醒；拖动不误开。减少动态效果只保留静态忙碌提示。

架构：TaskHost从既有TaskStore读取未结束列表limit1，复用activity()读取运行/准入事实；Rust返回两个派生布尔值，不新增持久化/任务状态所有者。专用本地pet命令固定窗口身份，在blocking worker查询SQLite；前端只保留瞬时表现。忙碌动画复用既有呼吸/尾巴/响应变换，加明显的“忙碌”提示，不生成新素材。原生悬停维持窗口内同坐标系检测，查询周期不作为严格性能门槛。

## 同桌面与面板操作（2026-09-14用户补充）

面板与小龙必须在同一桌面/Space，同进程应用相同原生窗口集合行为；不切换到其他Space打开。鼠标从小龙跨间隙进入面板后保持，面板上的现有任务按钮可操作；离开面板与小龙区域后隐藏，跨间隙留350毫秒宽限，已经进入面板后离开立即在下次原生观察隐藏。当前只读任务按钮仍为选择详情、刷新、分页，暂停/取消未接通不得假装执行。

小龙任务表现复用assets/mascot/互动动画生命周期-v1.md：真实执行占用映射executing（认真挥爪，约1.4秒循环），等待用户映射waiting_for_user，暂停/中断映射paused，其余idle。执行优先，非执行时首个未结束任务作为代表（按任务ID）；成功/失败一次性动画仍需真实事件去重，当前快照不重播。executing使用同角色透明四帧素材，不把整张PNG变换伪装成局部挥爪。此补充覆盖此前新增文字忙碌标记的工程建议。

执行素材alpha门禁失败，采用已授权既有透明素材爪部分层方案，见assets/mascot/互动动画生命周期-v1.md最新补充；无新增图像解码依赖。

托盘手动打开直到首次移入面板前保持，首次进入后应用移出隐藏；修复共享退出检测对手动入口错误应用跨间隙超时。

当前步骤增量：详情选择使用一次 `task.step.get` 同时取得快照与最近 Agent 声明；无声明明确显示缺失，列表不查询步骤。异步轮次保护、错误反馈和纯文本渲染沿用现有实现。
