# 设计

Harness 对两个候选提交相同 JSON 用例：读取文本、按稳定位置替换文本、另存、校验和冲突测试。实现只修改目标 XML part，其余 ZIP entry 原样复制；不实现复杂排版、图表、宏或旧二进制格式。

样本包含最小合成样本和 Microsoft Open XML SDK 官方 Transitional DOCX/XLSX/PPTX。合成样本用于确定性自动检查，官方复杂样本的输出必须由 WPS 实际打开，作为兼容性门禁。输出由独立校验器检查 ZIP、未修改 part 和预期文本。

首版只验证局部文本/单元格值修改。复杂结构操作降级 CUA，不为未来需求预建文档对象模型。
