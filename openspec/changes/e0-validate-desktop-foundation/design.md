任务门禁：运行中或任务状态未知必须保持展开；所有任务结束后重新开始 3 分钟倒计时。原生层在停靠前再次检查。E0 原型尚无后台任务执行入口，初始已知任务数为 0；计数只能由原生宿主更新，不向前端暴露设置计数命令。正式 Application 任务源、任务启动时自动唤醒及结束时重置计时仍需在任务宿主接线时完成，本批不宣称已接通。

原生渲染修复：外置 pet.css 后，旧 CSP 的 style-src 仅允许 unsafe-inline，导致 WKWebView 拒绝样式，原图按 1254×1254 绘制并被小窗口裁切。改为 style-src 'self'，仅允许应用同源样式，不放开外部来源。启动诊断 report_pet_render 仅接受 pet 窗口的布尔值及数值（图片解码、尺寸、样式加载），不接收或记录页面正文，属于 Spike 内部验证接口，不是 Agent Gateway 协议。

不可见启动修复：启动时通过 Tauri 的 primary_monitor 计算主屏幕中心，再 show/set_focus 显示窗口；无主屏幕信息时才回退 center，不依赖辅助功能权限。仅记录窗口尺寸、位置、可见性与页面加载阶段，不记录页面内容。macOS 本机预览使用最小 `.app` 包装，由 LaunchServices 启动，避免裸二进制依赖终端生命周期；该包装不用于正式签名发布，不新增产品协议或依赖。

基础动画增量：E0-S1 内验证固定内置页面的呼吸、眨眼与点击反馈，不实现任务状态映射。CSS 只变换图片，原生窗口位置由拖动管理；闭眼参考图仅在双眼内部以渐变遮罩显示，背景及身体始终沿用原始透明 PNG。页面脚本只维护短暂动画/指针状态；移动超过 4 像素才调用 Tauri 原生拖动，复用现有启动拖动权限。隐藏、失焦、减少动态效果时停止循环；恢复不补播历史动作。用户导入素材包仍禁止脚本，本批 JS 属于固定内置 UI。

使用官方 Tauri 2 最小模板；Rust Core 同进程运行 Local Socket echo 服务，CLI 仅发送一条带版本的 JSON 消息。先在当前 Linux 开发环境证明可编译性，再在 Windows/macOS 实机执行相同验证。Spike 代码不得提前拆成正式六 crate Workspace。

`interprocess` 统一 Listener/Stream API，但名称构造允许最小平台分支：Windows 使用 `GenericNamespaced` 映射 Named Pipe，Unix/macOS 使用 `GenericFilePath` 映射文件型 Local Socket。不得将该差异扩散到协议或 Application 层。

## 2026-09-14 用户变更：九态专属循环

来源：用户“呼吸眨眼所有的状态都要有”“每个状态都要有自己的动作动画重复播放”。覆盖此前完成/失败单次、等待/暂停仅保持的视觉播放规则。状态退出立即打断，不重复发布事件或自动恢复任务。九态独立呼吸、3～5秒眨眼，并按状态循环：idle呼吸摇尾；listening抬身点头；thinking交替歪头、尾尖轻摆；executing短臂围绕肩部交替抬落；waiting_for_user举爪姿态轻点头；paused收翼姿态慢下沉放松回位；recording专注姿态慢摇尾；success轻跳落稳；failed低头后回看用户。暂停首版不反复展开翅膀。减少动态效果、拖动、隐藏停止装饰动作。

采用现有透明关键姿态与连续变换，不用全身交叉换帧模拟挥爪；不新增依赖、状态所有者或任务协议。四个真实来源状态沿用产品播放器，其余五态仅在独立预览模拟。验收逐态观察至少两轮动作、呼吸、完整闭眼再睁眼，执行爪根不断裂、背景无格子。浏览器证据不替代原生验收，Windows继续暂缓。


### 九态循环返工：专属动作必须可辨认

### 录制道具与动作语义（用户验收目标）

来源：用户要求准确表达状态，举例“录制这种可以拿出相机拍照闪光之类的，可以用道具来丰富动作”。录制改为双爪抱相机：低位准备、平滑举起、短暂停留拍照、局部低强度闪光、平滑放下，每轮4.8秒。相机与前爪共享运动锚点；红色录制指示稳定显示。闪光仅在镜头附近、每轮一次，不覆盖屏幕，不影响点击/拖动；减少动态效果保留静态相机与红点，不闪光。相机为独立透明位图，保留生成原图。

当前录制真实来源尚未接线，只在独立预览模拟；不得启动真实录制或调用拍照能力。验收需看到举起/放下、镜头附近闪光、连续呼吸眨眼，记录长周期和透明背景证据；用户满意尚未证明，不可用transform变化宣称完整目标通过。
