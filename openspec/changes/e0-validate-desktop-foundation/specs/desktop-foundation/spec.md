# 桌面基础栈增量规格

## ADDED Requirements

### Requirement: 目标平台桌面能力验证

验证程序 SHALL 在 Windows 与 macOS 上证明透明无边框置顶窗口、托盘和基础生命周期可用。

#### Scenario: 启动验证程序

- **WHEN** 验证者在目标平台启动程序
- **THEN** 桌宠窗口与托盘均可见且可交互
- **AND** 退出后不得残留受管进程

#### Scenario: 托盘找回与退出

- **WHEN** 用户打开原生托盘菜单
- **THEN** 可以选择“显示小龙”恢复可见状态，休眠时沿用已有唤醒流程
- **AND** 选择“退出 Yonda”正常退出应用；不增加任务执行或持久化能力

#### Scenario: 拖动桌宠窗口

- **WHEN** 用户按住小龙桌宠区域的鼠标左键并移动
- **THEN** 无边框窗口通过 Tauri 原生窗口拖动跟随移动，松开后停止
- **AND** 不选中文字，仅 `pet` 本地窗口获得启动拖动权限，不增加其他窗口权限或依赖
- **AND** 此验证不包含重启后位置恢复；Windows/macOS 分别保留原生验证结果

#### Scenario: 透明小龙形象

- **WHEN** 启动接入小龙 PNG 的桌面验证程序
- **THEN** 窗口只展示一只完整小龙，不显示文字、色块、边框、阴影或滚动条
- **AND** PNG 透明区域和页面背景透出桌面，图片区域保留原生拖动
- **AND** Windows/macOS 分别保留视觉证据，缺失平台不得标记通过

### Requirement: 基础动态交互

#### Scenario: 打包页面样式加载

- **WHEN** 原生 WKWebView 加载打包后的内置页面
- **THEN** CSP 允许同源 pet.css，图片布局尺寸为窗口内约 188×188 逻辑像素
- **AND** 不允许外部来源样式，不显示方框焦点描边；验证必须覆盖原生渲染，不能仅用 file 页面通过代替

#### Scenario: 呼吸与眨眼

- **WHEN** 页面可见且用户未启用减少动态效果
- **THEN** 小龙每 3.6 秒轻微呼吸，每隔 3–5 秒短暂眨眼，轻微歪头、偶尔起伏及摇尾巴；保持透明背景，不移动 OS 窗口
- **AND** 原生窗口真正隐藏或最小化后停止，恢复后重新计时，不积压动作；未激活但可见时继续动画

#### Scenario: 未激活的原生小龙仍活动

- **WHEN** macOS 原生窗口可见，但 WKWebView 报告 document.hidden=true 或没有焦点
- **THEN** 以原生窗口可见性判断，继续呼吸与自然眨眼
- **AND** 不因频繁 focus/blur 反复重置眨眼间隔；减少动态效果时仍停止

#### Scenario: 点击与拖动区分

- **WHEN** 主指针按下并在 4 像素以内松开
- **THEN** 播放一次约 400 毫秒的点头反馈；快速连点不堆积动画
- **WHEN** 移动超过 4 像素
- **THEN** 调用原生拖动且不播放点击反馈
- **AND** 减少动态效果时保持静态；不创建任务、不录音、不录制

### Requirement: 桌面常驻与边缘休眠

#### Scenario: 切换桌面空间

- **WHEN** macOS 用户切换普通桌面 Space
- **THEN** 同一桌宠窗口保持原坐标可见，不随 Space 切换消失，不重新居中
- **AND** 不把 macOS 结果用作 Windows 虚拟桌面验证

#### Scenario: 闲置停靠

- **WHEN** 小龙 3 分钟没有本窗口指针或键盘交互，且未处于按住/拖动阶段，原生宿主确认没有后台任务执行
- **THEN** 播放缩身动画，在当前显示器最近的边缘显示双眼探头入口：底部趴伏、侧边探头、顶部倒挂
- **AND** 底边使用工作区下沿贴近 Dock/任务栏，左右贴显示器边界，顶部避开菜单栏；水平入口 112×56、侧边 56×112
- **AND** 停止休眠中的身体动作，但每 3–5 秒眨眼；减少动态效果或原生窗口不可见时停止，不监控全局输入，不改变任务状态

#### Scenario: 最近边缘选择

- **WHEN** 小龙位于当前显示器任意位置并满足收起条件
- **THEN** Rust 比较窗口到四条可停靠边缘的距离，等距按底、左、右、顶稳定选择
- **AND** 负坐标和不同缩放的显示器均使用物理坐标比较，入口位于当前屏幕可用范围，不误落到相邻屏幕

#### Scenario: 点击唤醒

- **WHEN** 用户点击双眼探头入口或按 Enter/空格
- **THEN** 恢复停靠前尺寸与位置，播放出现动画，重新开始闲置计时
- **AND** 连续点击不重复停靠或覆盖原位置；显示器移除时恢复到可用工作区
- **AND** 减少动态效果时直接切换；原生命令失败保留可重试的可见形态

#### Scenario: 辅助功能按钮激活

- **WHEN** 系统辅助功能对已命名桌宠按钮执行语义激活（macOS AXPress）
- **THEN** 休眠时沿用唤醒流程，清醒时沿用点击反馈，不要求伪造指针坐标
- **AND** 普通鼠标点击不因后续click事件重复唤醒或重复反馈

#### Scenario: 后台任务阻止隐藏

- **WHEN** 存在后台运行任务或任务状态未知
- **THEN** 原生停靠命令拒绝隐藏，前端恢复展开形态
- **AND** 所有任务结束后重新开始完整 3 分钟计时；正式任务源接线完成前此条件不得标记全部通过

### Requirement: 本地 IPC 验证

验证程序 SHALL 使用 Local Socket 完成同用户进程间的版本化 JSON 往返，且不得监听 TCP 端口。

#### Scenario: CLI 执行 echo

- **GIVEN** 桌面 Core 正在运行
- **WHEN** CLI 发送带版本的 echo 请求
- **THEN** Core 返回相同 payload 与服务端版本
- **AND** 非当前用户不得获得访问权限

### Requirement: 性能证据

验证程序 SHALL 在每个目标平台记录启动、空闲 CPU、空闲内存和窗口事件延迟。

2026-09-14用户变更：当前研发阶段性能预算作为优化目标，不阻断已验证功能推进；启动渲染ready=true可判本机启动功能通过，保留实际计时。完整交互、平台覆盖、安全及一致性分别验收，发布前重新评审预算。

#### Scenario: 执行空闲基线测量

- **WHEN** 程序稳定空闲五分钟
- **THEN** 证据包含测量方法、环境和原始结果
- **AND** ADR 明确说明是否达到架构预算

## ADDED Requirement：桌宠环绕图标菜单

关联 E0-S1、AD-E0-01；Architecture Impact：conforming。仅验证现有透明窗口内的展示交互，不新增原生协议、窗口或任务状态源。

### Scenario：点击展开与操作分流
清醒时轻点小龙，在同一 200×200 透明窗口内环绕展开图标；菜单期间小龙临时缩小，收起恢复原尺寸。再次轻点、Esc、失焦或开始拖动收起。拖动不打开菜单；边缘探头点击仅唤醒。键盘 Enter/Space 可切换，按钮具有名称和可见焦点。

### Scenario：入口与闲置
菜单包含任务空间（暂不可用并明确标注）、躲到边缘和收起菜单。躲藏复用原生任务门禁，失败保留小龙；菜单交互重置三分钟计时。不得用假任务数据冒充已接入 Task Space，也不得新增录制或发送动作。图标不超出窗口，不扩大透明窗口对桌面的点击遮挡。

### Requirement: macOS 全屏 Space 辅助显示
候选桌宠 SHALL 在其他应用全屏 Space 中保留原位置可见的桌宠/眼睛入口，不抢占全屏应用焦点。

#### Scenario: 进入并退出全屏
- **WHEN** 纯色原生测试窗口进入全屏，稳定 4 秒后再退出
- **THEN** 同一桌宠窗口在前后保持位置及尺寸，全屏期间对应屏幕区域仍有小龙，测试窗口仍处于激活状态

### Requirement: 九状态小龙素材

四状态运行时接线子范围关联DS-S1 RUN-ASSET-01～04、AD-DS-01：UI SHALL仅消费已有pet_task_state，预解码失败回退旧透明形象。执行1.4秒完整四帧循环；切到等待/暂停立即打断，500/300ms后保持；不可见、拖动、减少动态效果冻结；unknown静态不显示执行。其余五态无真实来源不得启用。
关联DS-S1 ASSET-01～04，Architecture Impact: none。素材 SHALL 对应互动动画生命周期-v1.md九状态，保留原图，PNG/WebP透明帧及声明式清单不含可执行脚本。

### 场景：真实 Agent 请求驱动收到请求展示

- **当** 已握手 Agent 的 `task.create` 成功返回
- **那么** 桌面宿主 SHALL 在无真实执行占用时短暂派生 `listening`
- **并且** 拒绝请求不显示，executing 优先，脉冲结束后重新展示 SQLite 派生状态
- **并且** 该展示不得写任务状态、事件、Outbox 或新增 wire 字段

### 场景：隐藏态随展示状态变化主动唤醒

- **假如** 小龙已处于边缘双眼形态
- **当** `pet_task_state` 返回与上次成功快照不同的展示状态，或查询从已知态变为 unknown
- **那么** 小龙 SHALL 调用既有恢复路径并展示最新状态
- **并且** 相同状态轮询、首次读取及恢复中的后续变化不得重复启动恢复

#### Scenario: 素材静态验收
- **WHEN** 内置imagegen生成图集并按用户授权本地提取透明帧
- **THEN** 九状态各四帧具有相同400×400画布、真实alpha及安全边距；播放规则区分循环、过渡保持和单次，录制标记独立；语义或边缘失败不得称可接入
- **AND** 静态验收不替代双平台原生动画与真实任务触发验证
