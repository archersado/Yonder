# DS-S1 三分钟闲置计时独立 Verification Goal

Story：DS-S1；OpenSpec：e0-validate-desktop-foundation；日期：2026-09-13。

依据：增量规格「闲置停靠」及用户明确的三分钟要求。状态：本机单次无任务闲置计时与几何收起通过；其他生命周期门禁保留。

## 方法

check-idle-macos.swift 使用单调时钟，在调用既有托盘wake探针前开始计时。wake通过“显示小龙”重置前端闲置计时，包含AX查找、事件派发以及探针800ms等待。随后约每250ms只读CG窗口尺寸，要求同一窗口编号且应用未隐藏，不注入前端时钟、不缩短180000ms常量、不更改任务状态。

观察上限190秒；本次判据为179秒后仍有展开样本、首次收起不早于180秒且小于185秒。185秒为本轮实验容差，非新增产品承诺。计时记录包括调用开销与既有320ms缩身动画，不能反推JS定时器精确到毫秒的触发时间。

据此确认本机没有提前收起，并在三分钟后进入横向探头几何。只凭尺寸不确定其位于顶部还是底部，未据此记某边视觉通过。事后独立截图 idle-timing-20260913-docked.png 实际显示完整展开小龙，不能作为停靠瞬间视觉证据；文件保留并明确其内容，避免按文件名误判。图像与测量并非同时取得，不推定展开原因。
