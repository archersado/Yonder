# DS-S1 小尺寸素材生命周期独立 Verification Goal

Story：DS-S1；OpenSpec：e0-validate-desktop-foundation；日期：2026-09-13。

依据：DS-S1 产品需求「三分钟闲置靠最近屏幕边躲藏」及增量规格「闲置停靠」「托盘找回与退出」。本轮只验证现有 macOS 右侧休眠与托盘唤醒，不修改实现。

状态：右侧自动收起与托盘恢复的本机视觉闭环通过；精确三分钟计时及完整生命周期门禁未关闭。

## 方法

复用仓库 check-wake-visible.swift，编译成临时原生工具，限定 bundle ID 与 PID 15225。只截取小龙窗口及其对应屏幕区域；通过原生 AX 菜单“显示小龙”唤醒，不额外激活应用。自然等待最多210秒，不缩短产品计时，不注入任务或修改状态。

## 已有休眠状态的唤醒

证据：`spikes/desktop-foundation/evidence/runtime-assets-wake-20260913/`。

工具退出0；窗口23237从右侧56×112恢复到200×200，唤醒后1秒和3秒截图均完整。屏幕区域实拍人工查看：休眠双眼可见，唤醒后主体和尾巴完整，两张清醒姿态有变化。没有出现只剩方框的情况。

该轮开始时已处于休眠，不能用于证明三分钟计时或完整自动收起过程。

## 从展开状态自然收起

证据目录：`spikes/desktop-foundation/evidence/runtime-assets-idle-cycle-20260913/`。工具退出0。初始窗口位于[1510,563]，尺寸200×200；不操作桌宠，自然收起到[1654,607]，尺寸56×112；托盘 AXPress 返回0，1秒及3秒后恢复[1510,563]、200×200。同一窗口23237，没有重建或居中。

人工核对休眠及两张唤醒屏幕区域截图：右侧双眼可见，唤醒后小龙完整，两张姿态不同，透明区域透出实际背景。窗口截图对应112×224和400×400像素，符合本机2倍缩放。

本轮从上轮唤醒后启动观察，期间经过命令授权和文档检查，观察器启动未重置计时；日志记录等待40秒后随后捕获休眠。因此证明自然自动收起及恢复位置闭环，不能用这40秒推导产品闲置阈值，也不能据此宣称精确180秒计时通过。原有180000毫秒常量未修改。

## 边界

无 Windows、其他边缘、多屏、任务忙碌接线或鼠标点击双眼唤醒证据。托盘 AXPress 不等于用户点击双眼。本轮不重复认定性能通过，也不解除 DS-S1 的其他门禁。
