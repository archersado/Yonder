# DS-S1 Windows 当前版本性能证据（2026-10-29）

## 结论

Windows 当前调试构建的五分钟自然闲置证据已补齐，进程全程存活并由验证器在采样后关闭；性能优化目标未达到。本项只表示“已有当前版本实测”，不表示 `<1% CPU / <150 MB` 通过。依据 Accepted AD-E0-01 和 2026-09-14 用户变更，数值预算当前为优化目标、不阻断已验证功能，但发布前必须重新评审。

## 环境与口径

- Windows 11 专业版 `10.0.26200`，64 位；Intel Core i7-13700F，24 个逻辑处理器，63.82 GiB 物理内存，显示缩放 150%。
- 二进制：`target/debug/yonder-desktop.exe`，SHA-256 `5203bc8cab914a359ab5529f4c89b0906e294327eaf8d79ca40e1ccdd71b6c25`。
- 原始结果：`apps/desktop/evidence/ds-s1-windows-20261029/native-resource-5min.json`。
- 从当前 Yonder 主进程开始反查全部后代进程；不包含 ego-lite、Codex 或其他祖先进程。每 5 秒采样一次进程树工作集求和和累计 CPU 时间。
- 自然闲置样本没有人为保持展开，预期跨越既有 180 秒边缘休眠；本轮未同步记录几何，因此不能仅凭资源数据证明停靠时刻。停靠功能另由 `verification-windows-idle-dock-20261025.md` 和 `verification-windows-edges-wake-20261029.md` 证明。

## 结果

- 请求 300 秒，实际 304.625 秒；55 个样本，最多 13 个归属进程。
- 工作集求和：平均 863.84 MiB，P95 889.66 MiB，峰值 917.57 MiB。
- 进程树累计 CPU：按单核 100% 口径平均 21.9259%，峰值 42.0%；按本机 24 个逻辑处理器归一的平均值为 0.9136%。
- `<1% CPU` 的架构目标指既有单核口径，不能用整机归一值替代，因此 CPU 与内存优化目标均未通过。
- 相较 2026-10-23 样本的平均 857.08 MiB、峰值 863.50 MiB、单核平均 31.3848%，本次 CPU 较低但内存峰值更高；两次均证明当前 WebView2 完整进程树远高于 150 MB，不能用仅宿主进程数据宣称达标。

## 边界

本证据关闭 `tasks.md` 的“Windows 当前版本性能证据”缺失，但保留性能优化待办、核心窗口状态更新延迟、macOS 完整可用状态和 DS-S1 总 Goal。采样未执行 CUA，也未启动 ego-lite。
