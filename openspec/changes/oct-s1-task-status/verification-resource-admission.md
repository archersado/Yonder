## 实测

`cargo test --workspace --offline --locked`：13 项通过，0 失败，构建 1.11 秒。新增两个 Application 测试覆盖：

- 不同文件身份可同时占用，相同文件、第二个桌面、第二个浏览器被拒绝；多资源申请失败不留下部分占用。
- 容量边界、重复任务、非法任务标识、空文件身份及超量资源被拒绝。
- 显式确认停止释放后可以重新准入；凭证丢弃仍保留占用，不将 unknown 当作完成。
- 接管期间拒绝新桌面准入，后台仍可准入；显式归还后恢复桌面准入。
- 8 个真实线程经屏障同时申请并保持占用：容量 3 时恰好 3 个成功；同桌面竞争恰好 1 个成功。全部确认停止后可再次申请。
- 既有 SQLCipher 事务、归属隔离、握手、生命周期和派生协议回归通过。未添加依赖，未修改数据库或传输模型。

## 限制

没有运行真实任务，也没有写文件或控制桌面。文件身份使用合成值，路径别名/硬链接解析仍是可信 Adapter 待办。同文件资源当前保守独占，不提供共享读锁。资源等待原因仅为内部类型，尚未生成 UI 协议或展示。

资源凭证无自动释放；误丢弃会保留占用直到受控宿主恢复。这是为了避免误放行尚未停止的副作用。宿主的单实例、恢复、开始状态事务、执行停止确认和用户输入暂停必须接线后才能产品使用；本批不声称已具备安全并行执行器。
