# TM-S1 创建去重寿命与事件预算闭合

Story：TM-S1。Architecture Impact：conforming。关联 AD-TM-01、AD-TM-06、AD-TM-22。

## 动机

创建幂等映射已经持久化并能返回原任务，但桌面组合根把所有成功的 `task.create` 都当成首次创建，网络重投会再次触发桌宠“新任务”瞬时提示。与此同时，TM-S1 文档仍把事件编码预算和去重寿命标为待决，规格与既有实现不一致。

## 范围

- 定案单事件 8 KiB、完整事件响应 256 KiB 的实际编码预算。
- 定案创建幂等映射与任务审计同寿命、无短 TTL；取消和终态不移除映射。
- Application/Adapter 返回首次创建或幂等命中的内部结果，桌面只对首次创建发出瞬时信号。
- 增加跨重启、终态、配额与编码边界回归。

不新增 wire 字段、SQLite 表或迁移，不实现历史删除、通用请求回执、自动重试或 Windows 验证。
