# task-lifecycle Delta

## ADDED Requirements

### Requirement: 创建重投不得产生第二次展示副作用

系统 SHALL 将首次创建与命中既有幂等记录区分，并且只对首次创建发布宿主瞬时创建信号。

#### Scenario: 同内容重投

- **WHEN** 同一归属 Agent 使用相同幂等键、名称、说明和可信来源再次创建
- **THEN** 返回原任务，不新增事件或 Outbox，且不再次触发桌宠新任务提示

#### Scenario: 重启或终态后重投

- **WHEN** 进程重启后或任务进入终态后重投同一创建操作
- **THEN** 幂等映射仍返回原任务，且不把它视为首次创建

#### Scenario: 配额已满时重投

- **WHEN** 审计配额不允许新建，但请求命中同内容的既有幂等记录
- **THEN** 返回原任务；新的幂等键仍因容量不足而拒绝

### Requirement: 事件分页受实际编码预算约束

系统 SHALL 将单个事件限制为编码后 8 KiB、完整事件响应限制为 256 KiB，并只返回可容纳的连续前缀。

#### Scenario: 下一事件无法放入当前页

- **WHEN** 下一事件会令完整响应超过 256 KiB
- **THEN** 当前页在上一事件结束，下一页从最后实际返回序号继续，不跳过事件

#### Scenario: 首条事件超限

- **WHEN** 页首事件编码后超过 8 KiB或无法放入完整响应预算
- **THEN** 返回明确错误，不返回伪装完整的空页，也不静默截断内容
