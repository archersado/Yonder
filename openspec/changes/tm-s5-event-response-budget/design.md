# 设计

Application 校验身份与读取权限后取得最多 `limit` 条已提交历史，并按协商版本转成 Rust 协议事件。随后逐项测量 `serde_json` UTF-8 编码字节数，拒绝超过 8 KiB 的单项；在保留完整 JSON RPC 包络的前提下追加可容纳的最长前缀，整响应不超过 256 KiB。

预算是在版本投影后测量，因此旧客户端没有新增字段也可读取。因预算截断时不能丢失或跳过下一项；Task Space 已使用最后实际事件序号继续分页。若首项本身无法返回，则明确失败；若没有记录，返回正常空页。响应 ID 的实际转义长度参与预算，不使用固定假设。

验证用合成事件覆盖转义和边界，并用真实 SQLite 事件页检查最后序号续读。此增量不改变存储与对外事件形状。
