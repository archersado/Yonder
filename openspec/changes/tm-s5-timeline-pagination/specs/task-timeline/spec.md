# 任务时间线分页 Delta Spec

## ADDED Requirements

### Requirement：按已显示序号继续读取时间线

系统 SHALL 允许用户从最后实际显示事件的序号继续读取下一页，并保持严格递增顺序。

#### Scenario：存在后续事件

- **WHEN** 首批最后事件序号小于任务快照序号，用户选择加载更多
- **THEN** 系统以该最后序号作为排他游标请求下一页
- **AND** 将新事件按序追加，不覆盖或重复已有记录

#### Scenario：后续读取失败或响应失效

- **WHEN** 下一页读取失败、为空、序号不递增，或用户已切换任务
- **THEN** 系统保留已有记录并显示局部反馈
- **AND** 不推进游标、不污染当前任务详情
