# 设计

## 统一样本

1. 无权限请求启动应用，确认麦克风未开启。
2. 只读枚举平台语音框架、中文识别器、离线能力与当前权限状态。
3. 用户显式开始后申请权限，输入统一公开测试音频，观察部分与最终文本。
4. 覆盖静音超时、取消、设备切换、运行中撤权、断网和ASR不可用。
5. 停止后确认采集对象、音频队列、系统录音指示和Worker均释放。

## 有界要求

PCM使用固定容量队列；证据只记录布尔能力、阶段、耗时、峰值字节和错误码，不保存PCM或转写正文。具体超时和容量由双平台样本校准，不能照搬参考插件常量。

## 桌宠集成样本

debug预览中的麦克风入口附着在小龙上；同一Yonda进程创建贴近小龙的临时收音卡。开始、停止、取消和最终文字均由Desktop组合根桥接候选Adapter。采集阶段只覆盖显示为`voice_listening`临时态，复用抬头侧耳素材并显示麦克风提示；任务“收到请求”的`listening`仍显示✓，两者不得混用。结束后恢复任务状态。卡片与小龙使用相同Space行为，关闭卡片必须停止采集。

## 候选判定

优先选择能在两平台提供一致Application契约的最少依赖路线。平台原生实现允许Adapter内部不同，但必须产生相同状态与错误分类；单平台通过不接受ADR。
