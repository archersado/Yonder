# Proposal：VI-S1 单轮语音输入 Spike

关联Story：VI-S1；关联AD：Proposed AD-VI-01。

比较Windows/macOS单轮语音输入候选路线，验证权限、采集、转写、说话后短暂停顿自动结束、整段单条投递、停止和资源释放。debug预览复用Yonda进程与既有桌宠状态投影，提供小龙入口和同Space贴边卡片；不修改协议、SQLite或Gateway，不把独立测试App作为入口，不采集真实用户语音作为证据。

本轮静音判定补充验证期限为2026-10-09。届时如缺少任一平台的统一样本证据，只记录未通过并复审期限，不接受ADR、不进入依赖该路线的产品实施。
