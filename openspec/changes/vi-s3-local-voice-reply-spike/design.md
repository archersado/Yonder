# 设计

原生探针与产品进程隔离，只接收内置编号样本，输出布尔结果、计数和毫秒区间，不输出样本文字、声音名称、原始回调或音频。macOS 候选使用公开系统语音合成 API；Windows 候选使用公开系统语音合成 API。两端通过同一 JSON 字段比较能力，不以平台专属成功项掩盖另一端缺失。

顺序夹具模拟多个片段乱序完成：Application 原型只允许当前 generation 的 `next_sequence` 发布；新 generation、停止或连续失败会清空缓冲并拒绝迟到结果。队列采用固定容量，超限形成稳定失败，不阻塞调用线程。夹具只验证契约，不进入正式 Workspace，也不形成第二状态所有者。

原生停止样本先排入长句，在开始回调后请求立即停止，记录取消回调是否唯一、停止耗时和之后是否出现继续完成事件。离线性只有在真实断网环境中成功运行才能标记通过；“声音已安装”或 API 文档不能替代离线证据。输出设备切换需要真实设备条件，缺失时记录阻塞。

macOS 子结论可证明候选继续保留，但不得接受 AD-VI-03。缺少 Windows 环境时，任务与 Story 保持未完成，不把产品代码接入正式组合根。
