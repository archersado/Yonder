# 命令任务

Command 默认是结构化 `program + args + cwd + env`，不是 shell 字符串。

## 执行顺序

1. 明确可执行程序、逐项参数、工作目录、最小环境和超时。不要把多个命令拼成一段 shell。
2. 调用 `task_command_propose`。该调用只生成本机预览和一次性命令引用，不代表已执行。
3. 等待用户在 Yonder 审阅并批准。未批准、拒绝、过期或引用失效时不得启动执行，也不得换一种方式绕过。
4. 取得批准引用后，以最新任务序号调用 `task_command_execute`。同一引用只执行一次。
5. 根据 Yonder 的有界退出状态、截断标记和任务事件提交终态。超时、取消、断连或 `unknown` 不自动重试。

## 围栏

- Shell、提权、安装、删除以及其他高风险动作需要目标能力和明确确认；缺少正式入口就报告不支持。
- 不继承不必要的环境变量，不把凭据放入参数、环境、日志或任务描述。
- 不把完整 stdout/stderr 写入回复；只使用完成目标所需的有界摘要。
- 不使用通用终端工具替代缺失的 Yonder Command Gateway。
